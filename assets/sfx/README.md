# 音效文件目录

**丢文件就生效，不用改代码。** 文件名必须是下面清单里的名字，后缀 `.mp3`：

```
assets/sfx/swipe.mp3
assets/sfx/coin.mp3
...
```

没有对应文件的名字，游戏会用代码现场合成的占位音顶上（能听，但糙）。
放了文件就自动改用它——**改完刷新一下页面**（游戏不会热加载目录）。

| 文件名 | 什么时候响 | 建议 |
|---|---|---|
| `swipe.mp3` | 每滑出一张卡 | 很轻的纸片/风切声，≤0.15s |
| `tap.mp3` | 按钮、菜单点击 | 短促的按钮音，≤0.08s |
| `coin.mp3` | 发工资、外快到账、涨停 | 硬币/收银，≤0.5s |
| `pay.mp3` | 房租水电、大额消费 | 收银机/刷卡失败感，≤0.4s |
| `warn.mp3` | 四条命第一次掉进危险区（每局每项一次） | 两声短警报，≤0.4s |
| `thud.mp3` | 跌停、单日净值 −9% 以上 | 闷响，≤0.3s |
| `crash.mp3` | 泡沫破、上失信名单 | 崩裂/玻璃，≤0.8s |
| `teach.mp3` | 讲解卡出现 | 温和的提示音，≤0.4s |
| `reward.mp3` | 看广告领次数、领任务奖励 | 上扬的奖励音，≤0.8s |
| `win.mp3` | 活下来的结局 | 收束感的胜利音，≤1.5s |
| `lose.mp3` | 死掉的结局 | 下行的失败音，≤1.5s |

## 约定

- 格式：**mp3**（兼容最好）。想用 ogg/wav 或放别的目录：在 `prototype.html` 的 `SFX_FILE` 里显式登记，格式 `{ swipe: "assets/sfx/xxx.ogg" }`。
- 音量：游戏里的播放音量固定 `SFX_VOL = 0.7`。**请在源文件里把响度做齐**——混在一起听不出来的话，进 `tools/sfx-lab.html` 逐个点。
- 时长：短音效别超过 1.5 秒，长音效拖住手感。
- 命名：全小写，就用上表的名字；想加新音效得同时在 `prototype.html` 里加调用点。
- 单文件体积：每张 ≤ 40KB（整包音频控制在 400KB 内，小程序有体积限制）。

## 试听

双击 `tools/sfx-lab.html`，逐个点，会显示「文件已就位」还是「缺失→用合成音」。
