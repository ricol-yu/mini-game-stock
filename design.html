一、定位：给谁玩

面向泛用户，不是股民。术语全部改掉（降准 →「银行要放水了」；维持担保比例 →「你借的钱快不够抵押了」），一个专业词都不出现不影响玩法。真正的主线是人生两难：房贷、补习班、住院、裁员、女儿问你为什么总在看手机。

基调是黑色幽默 + 讽刺，笑点在"这件事真的会发生"，而不是谐音梗。副产品是教育意义——但它必须通过机制传达：加杠杆不产生任何净资产，只是把同样的本金暴露在更大波动里；这条规则本身就是最狠的一句评语，不需要旁白说一个字。

二、核心循环

抽一张卡→读它的两难→左右滑→属性变化→ 日终：行情 + 状态结算→四条同时逼近边界→结局

关键手感来自《王权》的两点：① 松手前能看到代价（拖到一半，红色/绿色印章浮出），犹豫感让人上瘾；② 每条选择的代价不对称——付了房贷保住社会、掉了现金，六个字段同时在动，所以每一滑都是多目标权衡。

三、四条属性

四条的危险方向刻意不对称，这是整个游戏张力的来源：

属性怎么涨怎么掉到边界会怎样界面
金钱 发薪（每 15 天）、私活、年终奖、股价上涨 房贷/住院/随礼/聚会每一次人生开销；亏损；借钱利息 净资产 = 现金 + 持仓 − 负债 ≤ 0 → 出局 一条双色：现金（橙）+ 持仓（红），右端斜纹 = 负债
心态 早睡、陪家人、承认现实、大涨带来的多巴胺 熬夜、说谎、被套、每笔亏损按跌幅扣 ≤ 0 →「不动了」
满格不致死，≥ 88 进入「上头」状态		 蓝
风险 配资、网贷、信用卡最低还款、内幕、荐股群、长期重仓 减仓、还债、时间（每天 −0.15，消退极慢） ≥ 100 →「爆了」
≥ 72 时每天有 7.5% 概率事情自己发生（被强平/催债上门）		 橙红
社会 赴宴、随礼、家长会、挽留、添丁 每拒绝一次人情；每天自然衰减 −0.22 ≤ 0 →「没有人」（通讯录很久没响过） 绿
「社会」是这套系统里最重要的一个改动。它是唯一一条必须花钱才保得住的属性——不经营就慢慢掉，经营就掉钱和心态。于是每一笔人情都有了双重身份：既是感情，也是成本。这在《王权》的四维里是缺失的那一维。

为什么心态满格不再是死刑

v1 里「心态 100 → 上头暴毙」在模拟中暴露出一个反直觉的错误：做所有正确选择的人会死得最快（早睡 +9、陪女儿 +9、陪家人 +9，全部理性选择叠加起来直接顶到 100）。这既不合理，也让游戏变成了反智。

v3 的改法是：心态高 = 你状态很好，纯收益；但 ≥ 88 会点亮「🎈上头」状态，这个状态下你的每次买入金额自动 ×1.35——不是判决，是诱惑。真正杀人的是那笔变大的单子，不是好心情。

四、状态系统（这套游戏的骨架）

《王权》最狠的一点是：有些选择不给你即时反馈，它开启一段持续若干天的处境，而之后的每一张卡都在那个处境里被重新解读。我们一共 7 个状态：

状态怎么来持续每天发生什么想传达的
🫧 泡沫「所有人」事件卡（第 8 天后） 直到自己破掉，最长 14 天 大盘每天额外 +2.8%；每天有 9% + 5%×天数 的概率破裂，一次性跌 30–58% 涨得越确定，越危险。唯一的解是提前下车——但下车要错过明天的涨幅
❄️ 冬天新闻头条卡（第 12 天后）12 天 大盘每天额外 −2.4%，心态 −1.3 系统性风险和你的努力无关
🚫 停牌交易所公告卡5 天 价格冻结、卖不掉、心态 −0.8 有些仓位你以为随时能退，其实不能
👶 添丁「我怀孕了」选择留下永久 每天 −180 元、心态 +1.0、社会 +0.4；解锁孩子专属卡 花钱，但它是少数能持续补心态的东西
📦 失业HR 卡（怎么选都会失业）直到找到新工作 每天心态 −1.1、没有发薪日、解锁求职卡 收入不是理所当然的
🕵️ 内线饭局上选择「记住这个消息」6 天 股票每天额外 +1.4%，但风险 +1.4/天；14% 概率某天发现「消息是假的」 内幕是收益的捷径，同时也是风险的快车道
🎈 上头心态 ≥ 88 自动进入心态回落到 74 以下自动解除 每次买入金额 ×1.35，风险缓慢上升 好心情不等于好判断
状态带来的三个额外价值：① 它们是解锁器——停牌中才会出现「复牌时间待定」，失业中才会出现「对方已读不回」，让不同周目长出不同的叙事线；② 它们制造记忆点——玩家记住的不是某张卡，是"那年泡沫破了我的那笔"；③ 它们让"时代"变成可操作对象，而不是背景。

八、数值平衡（600 局模拟验证）

原型跑了两组各 600 局对照实验——随机乱滑代表最差玩家的下限，按趋势操作代表理解了机制的玩家：

指标随机乱滑按趋势操作
平均存活36.1 天39.7 天
中位数34 天41 天
通关率16.5%31.7%
主要死法不动了 28.5% / 穿仓 19% / 泡沫之后 15%一无所有 34.5% / 泡沫之后 18%

技巧回报约 2 倍通关率，且死法结构明显不同：随机的人被情绪和杠杆杀死，会玩的人多半是被生活账单慢慢磨死——这正是想要的差异。对照过程中一共修掉四个设计缺陷：

① 心态满格即死 → 做所有正确选择反而死得最快。改成 100 不死、≥ 88 进入「上头」状态（见第三节）。
② 大盘是纯随机游走 → 趋势不可读，技巧无处安放，会玩和乱滑胜率几乎一样。改成 +0.3%/天长期漂移 + ±2.4% 周期振幅，并在 HUD 显示近五日涨跌——给玩家一个可读的信号，让"顺势"成为一种真实存在的策略。
③ 工资只在抽到卡时才发 → 理性玩家第 10 天就破产，游戏在行情还没开始之前就结束了。改成每 15 天自动发薪 7,500（失业后停发），这才符合"日子照过"的现实。
④ 风险条形同虚设 → 只有 0.3% 的人死在风险上。加入「≥ 72 时每天 7.5% 概率自己出事（强制平仓 / 催债上门）」，这条从此有了重量。
生活成本的绝对值用参数扫描定标：系数从 1.0 到 1.6 逐档实测，取 1.3——这一档上随机 16% / 会玩 34%，技巧差最大。

九、技术架构

做小程序，不做小游戏

本作是 UI 驱动（卡牌 + 动画）而非 Canvas 渲染。用小程序可以拿到 WXML/WXSS 布局、分享卡片、订阅消息、广告组件；用小游戏则所有中文换行都要在 Canvas 上手写。开发效率差一个量级。

手势实现要点

  • bindtouchstart / move / end 直接改 transform: translate3d() rotate()；不用已废弃的 wx.createAnimation，也不用 movable-view。
  • 拖动中关掉 transition，只在 touchend 打开，避免跟手延迟。
  • 阈值 78–90px，配 catchtouchmove 防止整页跟着滑。
  • 卡堆只留 3 个节点（当前 + 2 张底牌），滑出即回收。

十、⚠️ 合规与资质（路径已定：企业主体 + 游戏类目 + 纯激励视频）

内容层面的风险已经基本清零。单只无名股票——没有真实股票代码、没有公司名、没有真实行情，也就谈不上投资建议。需要保留的是：启动页与设置页常驻「本作纯属虚构，不构成任何投资建议」，且玩法上永远不要出现"教你赚钱"的引导。
资质才是真正的门槛，而且规则正在收紧，以下按 2026 年现行情况整理，提交前务必在微信公众平台后台核对最新清单。

· 软著是硬门槛：无论是否收费都需要《计算机软件著作权登记证书》。周期 30–60 个工作日，加急 7–10 天——这是整条链路上最慢的一环，应当在开发中途就同步申请，不要等做完再补。
· 工信部备案：所有小程序/小游戏都需要，通过公众平台提交，数日至数周。它和版号是两件事，不可互相替代。
· 版号：一致的说法是——开通虚拟支付（内购）必须有版号；仅靠广告变现、且属于平台允许的无版号品类，目前多数情况下不需要。但 2026 年有收紧的动向，存在"无版号一律清退"的说法。稳妥做法是：按"无版号可变现"推进，同时把版号当成 Plan B，一旦口径变化不至于停摆。
· 企业主体是必须的：2025 年 4 月起，微信已不接受个人主体的角色类游戏新增发布和线上更新。本作有大量人物关系与剧情，大概率被归入此类——企业营业执照 + 对公账户是前提。
· 名称查重：「韭菜之王」建议在微信搜索先查是否被占用，被占则及时改备选名，避免提交后被驳回。

执行清单（按时间顺序）

  1. 同步启动软著申请（今天就能开始，不阻塞开发）——这是最短板。
  2. 企业营业执照 / 对公账户齐备，完成微信认证。
  3. 开发到可玩版本后：上传代码 → 提交工信部备案 → 提审（内容审核一般 3–7 个工作日）。
  4. 累计独立用户达到门槛后开通流量主，接入激励视频。
  5. 同步评估版号（海南、苏州等地有扶持政策与集中受理通道）。

变现：为什么激励视频和这个游戏天生一对

本作的核心节奏就是「死 → 再来一辈子」，复活点天然存在。可用的点位：① 死后看广告原地复活一次（本金减半，最自然）；② 翻倍本局的最终收益（结局页）；③ 解锁每日挑战（固定种子，同一天所有人的卡序一样，适合做排行榜）。

另外，微信平台对 IAA（广告变现）游戏有流量激励政策——2026 年再次上调，活跃时长门槛已降到"累计 3 分钟"量级，长线流水的激励周期延长到 180 天。纯广告路线在平台侧现在是被鼓励的，这进一步支持了路径选择。

十二、还差一个名字

第四条属性「社会」到底叫什么？

UI 上只能放 2–3 个字（「金钱 / 心态 / 风险」都是两个字）。它的内涵是：人情世故、家庭琐事、那些不付代价就会慢慢失去的东西。

人情 —— 最准，且和中文里"还人情 / 欠人情"天然接得上；缺点是覆盖面偏窄（同事那份有点勉强）
牵挂 —— 最有余味，贴合游戏的调性；缺点是不像消耗品，新手可能读不懂为什么会掉
关系 —— 最直白
世故 —— 呼应"人情世故"，略文言
保持「社会」不动 —— 够口语，够荒诞
