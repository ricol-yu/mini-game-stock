**这一版最重要的一句话**：B 档现在**不是一个人**，是玩家自己手里那张纸。
给票配一张脸，等于给玩家的贪心配一张脸——方向就错了。所以它没有形象，永远空镜。

**「不上角色卡、不出立绘」不是省钱，是视觉语言**：
- 角色卡是「这个人会再来」的承诺。B 档不是人，A 档不需要被介绍——**本期没有一张角色卡要出**（组件存档在 §4）。
- A 档小王虽然高频，但他的 3 张卡本身就是 3 个具体场景；再给他一套立绘 = 同一件事画两遍。
- C 档两人靠「突然出现」，一张脸会让玩家开始「同情」或「讨厌」——两种情绪都会毁掉那个角色。

## 1. 你的票 `nidepiao`（B 档 · 唯一真支线 · **没有形象**）

### 1.1 三条铁律（出图前先读，违反任一条就打回）

1. **永远是空镜。** 每个节点一张静物，画面里**没有人**。
2. **不许出现人形。** 包括：正脸 / 侧脸 / 背影 / 剪影 / 镜中倒影 / 玻璃反光里的脸 / 画面外伸进来的一只手 / 投在墙上的影子。
   连「一只手在操作手机」也不行——那只手是玩家，玩家不在图里。
3. **不许可爱化、不许拟人化。** 不许给票画眼睛、不许画成小人、不许加表情气泡、不许把它做成吉祥物。

> 写 prompt 时把这句话放最后一行，压住模型：**"Empty room, nobody is here. No people, no hands, no silhouette, no reflection of a person."**

### 1.2 avatar：只有三个，且互斥

| 状态 | avatar | 色（纸上） | 用在哪 |
|---|---|---|---|
| 涨（账面在赚） | **📈** | `#c9302a` | 该节点净值 > 成本 |
| 跌（账面在亏） | **📉** | `#157a44` | 该节点净值 < 成本 |
| 还攥着（不涨不跌 / 平） | **🔴** | `#a8281e` | 净值≈成本、或"我还没卖"这类节点 |

- **同一节点只允许一个符号**，不许 📈📉 并排（那是把两个时间点塞进一张脸）。
- 🔴 不是"红灯/危险"，是「**这一格还亮着**」——票还在手里。别用 🟢、别用 💰、别用 🎫（🎫 会被读成"演唱会门票"）。
- 这三个符号**不承担人物语义**，所以共用同一个「持票者」语义槽，不需要一角色一 emoji 的规则。

### 1.3 空镜库（**只准用这 5 个景，别自己加**）

| # | 景 | 一句话构图（接在 art-prompts §1.1 之后） | 用在哪 |
|---|---|---|---|
| S1 | **桌面 + 亮着的屏** | 【本张】深夜木桌的近景，一台笔记本电脑斜放着，屏幕朝画面右前方亮着，屏上只有抽象色块与一条上扬的曲线（**无数字、无刻度、无文字**）；桌角一只马克杯已经没热气；背景全暗，只有屏幕的冷光打在桌面上。 | 交易日 / 下单 / 加仓 |
| S2 | **一杯凉了的水** | 【本张】餐桌一角的近景，一只玻璃杯只剩三分之一，水面平静、无反光人影；杯壁外侧有一圈干掉的水痕；旁边是摊开的手机，屏朝上、已熄灭。午后侧光。 | 等待 / 犹豫 / 装死不看 |
| S3 | **深夜窗 + 台灯** | 【本张】窗台与台灯的中近景，窗外是虚化的城市夜灯与雨点，室内只有台灯一小圈暖光；窗玻璃上**只有灯的反光，没有人影**；桌面散着两张纸。 | 睡不着 / 加杠杆 / 深夜复盘 |
| S4 | **桌面 + 外卖盒** | 【本张】桌面的俯拍近景，两只吃空的外卖盒、一副筷子、一罐没喝完的饮料；电脑在画面边缘只露一角；顶光偏冷。 | 连亏 / 沉迷 / 生活塌陷 |
| S5 | **手机贴桌面** | 【本张】一张手机平放在木桌上的俯拍特写，屏朝上、亮着，屏上是一条**向下**的抽象曲线（无数字无文字）；旁边一把钥匙、一枚硬币。 | 清仓 / 认输 / 最后一眼 |

**共同约束**：中近景、单一光源、主体在下方 1/3、**中央留低对比区**（文字要压在这儿）、画面内 0 个文字 0 个数字 0 个 logo。

### 1.4 配色：不设角色主色

- 它的"颜色"就是**涨跌**：涨 `#c9302a` / 跌 `#157a44` / 血亏 `#a8281e`（纸上，均 ≥4.9:1，见 `share-card-spec.md` §7）。
- 空镜本身走冷调（蓝灰、暗木、暖黄台灯），**不要给它加品牌色**——一加就变成"某个角色"。
- 与 A 档区分：A 档的画面有人、有暖光、有生活气；B 档的空镜**冷、静、无人**。同一屏里出现时，一眼能分出"有人的房间"和"没人的房间"。

### 1.5 与分享卡 T5 的关系（已定，别再动）

T5 温情版 = **纯场景 + 文字**，用的就是这里的空镜（S1~S5 任一），**不叠人物层**。
参数见 `share-card-canvas.md` §4.5：640×720 素材按 `s = max(1080/640, 1040/720) = 1.6875` 铺满 1080×1215，顶部对齐，溢出 175px 交给底部压暗吃掉。

## 3. 配角规则（视觉侧要守的部分）

1. **配额分档**：C 档（张阿姨 / 司机）单局 ≤1 次；小王 A 档 **≤5 次/局、间隔 ≥6 张、第 3 天前不登场**。
   视觉上的含义：小王的头像**会在一局里反复出现**，所以他的色块必须是最不抢戏的那一档（冷蓝 + 18% 底），不能比 A 档主体更亮。
2. **都不许出现在支线位**（支线位只属于 `nidepiao`）。
3. **不给他们"后来"**：不写"三个月后他……"，不给二次卡。
4. **一个 emoji 不许换**（👔 / 🧶 / 🚕），换一次=换了个人。
5. **不复用口头禅**：三人各有 3 句，任何两句不许撞句式；小王同局出现多次时，**三张卡必须是三句不同的话**。
6. **不设同局互斥**：张阿姨、司机各自 ≤1 次/局（由单人 `_onceCnt` 管住），两人可与小王、也可**彼此**同局。撞面时是「先被阿姨劝一嘴、晚上又被司机上一课」，两件糟心事叠着，情绪是累加的——这是加分不是减分。
7. **只走社会心态这条线**，不改硬数值——他们劝得动你的心，劝不动 K 线。

## 4. 角色卡组件（**存档 · 当前无 B 档人物使用**）

B 档现在不是人，所以这套组件**本期不上线**。留在这儿，是因为将来若真出现一个"会再来的人"，
直接复用这份数值，不用重画。

```
┌──────────────────────────────────────────────┐  343 × 100
│▌┌──────┐  <名字>            [第 N 天]        │  ▌= 角色色竖条 6
│▌│ 👔  │  「一句招牌台词。」                   │     头像 72×72 r12
│▌└──────┘  <角色关系一句> · 现 N 张            │
└──────────────────────────────────────────────┘
```

| 元素 | 规格（375 基准，落地 1px → 2rpx） |
|---|---|
| 卡体 | 宽 343（内容列满宽），高 100，圆角 14，3px `--u2-edge`，底 `--u2-card`，硬影 `0 7px 0 rgba(11,32,22,.45)` + 柔影 `0 16px 26px rgba(0,0,0,.26)` |
| 角色色竖条 | 贴左边，宽 **6**，通高（靠 `overflow:hidden` 被圆角自然裁出） |
| 头像位 | 72×72，圆角 12，2px `--u2-edge`，底 = 角色色 18~20% alpha，emoji **38px** 居中 |
| 名字 | 16 / 900 / ls .5px，`--u2-ink` |
| 阶段胶囊 | 9 / 800，内距 `4px 6px`，圆角 8，描边 1.5px 角色色，底 `rgba(43,31,18,.05)`，字 `--u2-ink`，不换行 |
| 招牌台词 | 13 / 1.65 / 600，`--u2-ink-2`（6.13:1），**1 行 ≤18 字**，超了截断加「…」不缩字 |
| 元信息 | 10 / 1.6 / 600，`--u2-ink-3`（装饰行，不承载关键信息） |
| 卡内距 | 12；头像与正文间距 12 |

**三条硬规则**
1. **角色色永不作正文字色。** #5aa9e6 / #d9733c / #f2b01e 在奶油纸上只有 2.2 / 3.0 / 1.8:1，连 3:1 都不到。
   色只上竖条、胶囊描边、头像底；名字和台词一律 `--u2-ink` / `--u2-ink-2`。
2. **一个角色一个 emoji。**「常驻」这件事第一眼就靠这个立住。
3. **人脸类 emoji 一个 `whoId` 最多一个**：`haizi` 锁 **🧒**（现有 👧🤒👶🧒 四个都是人脸且年龄不同，占位态下会变成四个孩子）；
   `laopo` 的 🏠🎁📵 是**处境符号**不是脸，**保持不统一**——那是设计意图。
   `nidepiao` 的 📈📉🔴 **不进入这条规则**：它不是人，没有"脸"的概念。
