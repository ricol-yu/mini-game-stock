## 1. 画布规格

### 1.1 主推：1080 × 1440（3:4）

| 项 | 值 |
|---|---|
| 画布 | **1080 × 1440**（比例 0.75） |
| 颜色空间 | sRGB，导出 PNG（无透明） |
| 目标体积 | ≤ 380KB（渐变 + 纯色 + 少量插画，PNG 可压；T5 有照片时走 JPG q88） |
| 最小可辨认尺寸 | 缩到 **270×360**（朋友圈九宫格单格）时，标题仍可读、金额仍可辨 |

**为什么是 3:4，不是 9:16**

| | 3:4（1080×1440） | 9:16（1080×1920） |
|---|---|---|
| 朋友圈单图 | **按 3:4 裁**，零损失 | 上下各裁 240，共丢 **25%** 画面（标题或页脚必丢一处） |
| 聊天窗口缩略图 | 缩到 ~180×240，接近原始比例 | 缩到 ~120×214，字先糊 |
| 抖音 / 视频号竖屏封面 | 需要上下补绒布，能用 | **原生合适** |
| 内容密度 | 一屏看完，不用滑 | 中间 480px 必须靠留白撑，容易「空得发慌」 |
| 实现成本 | 一套 | 一套 |

**结论：只实现 3:4。** 9:16 若将来要做，**不新增版式**——把 3:4 的渲染结果居中，上下各补 240px 纯绒布渐变
（复用同一渲染函数，加 `padTop/padBottom` 参数），页脚仍贴在 3:4 区域内。禁止为 9:16 重新排一遍内容。

### 1.2 1:1 变体（1080 × 1080）：只改下边距与字数上限

不新增版式，只做四处降级：

| 项 | 3:4 | 1:1 |
|---|---|---|
| 内容区纵向 | 72 → 1150（高 1078） | 72 → 928（高 856） |
| 页脚分隔线 | y = 1150 | y = 928 |
| 小程序码 | 168×168 @ (840, 1176) | **取消**，右下角改 48×48 圆角角标（印「韭」字，无静区要求） |
| quote 上限 | 34px × 3 行 = 81 字 | 34px × **2 行** = 54 字 |
| 数据项 | 3 项 | **2 项**（「最后剩下」＋「这一辈子」，其余丢） |
| T1 主标题 | 200px（≤4 字） | 168px（≤4 字），上限字数不变 |
| T5 插画位 | 1080×1040 | 1080×**620**，文字上移 |

> 字数上限是**硬上限**：超了不缩字，走 §5 的截断规则（保留前 2 句，句号处断）。

## 3. 全局元素的画法（canvas 2D）

### 3.1 底：绒布径向渐变 + 网格 + 噪点

```js
// 绒布：与主界面同源，中心在画面上方 15%
const g = ctx.createRadialGradient(540, 216, 0, 540, 216, 1560);
g.addColorStop(0,    '#2a7452');
g.addColorStop(0.56, '#17402f');
g.addColorStop(1,    '#0c2b1e');
ctx.fillStyle = g; ctx.fillRect(0, 0, 1080, 1440);

// 格子底纹：60px 一格，1px，极轻（0.045）
ctx.strokeStyle = 'rgba(253,243,216,.045)'; ctx.lineWidth = 1;
for (let x = 0; x <= 1080; x += 60) { ctx.beginPath(); ctx.moveTo(x + .5, 0); ctx.lineTo(x + .5, 1440); ctx.stroke(); }
for (let y = 0; y <= 1440; y += 60) { ctx.beginPath(); ctx.moveTo(0, y + .5); ctx.lineTo(1080, y + .5); ctx.stroke(); }

// 噪点：固定种子，1200 个 1~2px 白点，alpha .02~.05（防「纯色塑料感」，也防被抹掉重绘）
for (let i = 0; i < 1200; i++) {
  const x = rnd(i * 2 + 1) * 1080, y = rnd(i * 2 + 2) * 1440;   // rnd = 固定种子伪随机
  ctx.fillStyle = `rgba(253,243,216,${0.02 + rnd(i * 3) * 0.03})`;
  ctx.fillRect(x, y, 1 + (rnd(i * 5) > .8 ? 1 : 0), 1);
}
```

> 噪点必须**固定种子**：每次生成同一张卡的噪点位置要一致，否则同一张战绩连拍两次对不上，玩家会以为被篡改。

### 3.3 文字排版工具（canvas 必须自己算）

canvas 没有 `letter-spacing`、没有 `font-variant-numeric`、没有折行。三个函数必须自己写：

```js
// ① 字距：逐字 fillText，累加 measureText
function fillLS(ctx, text, x, y, ls) {
  let cx = x;
  for (const ch of text) { ctx.fillText(ch, cx, y); cx += ctx.measureText(ch).width + ls; }
  return cx - ls;                                  // 返回实际右端，供居中/右对齐
}
function measureLS(ctx, text, ls) {
  let w = 0; for (const ch of text) w += ctx.measureText(ch).width + ls; return w - ls;
}

// ② 居中 + 字距
function fillCenter(ctx, text, cx, y, ls) {
  const w = measureLS(ctx, text, ls); fillLS(ctx, text, cx - w / 2, y, ls);
}

// ③ 折行：中文按字切，避头尾
const NO_HEAD = '，。、；：？！）」』】》%…';   // 不许出现在行首
const NO_TAIL = '（「『【《';                    // 不许出现在行尾
function wrap(ctx, text, maxW) {
  const lines = []; let cur = '';
  for (const ch of text) {
    if (ctx.measureText(cur + ch).width > maxW && cur) {
      if (NO_HEAD.includes(ch) || NO_TAIL.includes(cur.slice(-1))) { cur += ch; continue; } // 挤一行
      lines.push(cur); cur = ch;
    } else cur += ch;
  }
  if (cur) lines.push(cur);
  return lines;
}
```

**数字对齐**：不要指望 tabular。T4 表格的金额一律 `ctx.textAlign='right'` + 固定右基准 x = 944；
T1/T3 的数据值同理。同一列的右边界对齐，视觉上就是等宽的。

**字体栈**（canvas `font` 必须带 family，否则安卓回落到衬线）：

```js
const F = '"PingFang SC","HarmonyOS Sans SC","Source Han Sans SC","Microsoft YaHei",sans-serif';
ctx.font = `900 200px ${F}`;
```

### 3.4 水印与防伪（轻量，可关）

两层，都不挡主体：

| 层 | 画法 | 强度 | 目的 |
|---|---|---|---|
| **A 全幅平铺** | 45° 旋转，`fillText('韭菜之王', …)` 20/600，格距 **420 × 320**，色 `rgba(253,243,216,.05)`，覆盖全画布（含插图区） | 5% 白，肉眼只在不经意时看到 | 防裁切、防抹水印：任何位置裁一刀都还带字 |
| **B 页脚行** | 见 §2.4：`结局 No.06 · 由《韭菜之王》生成 · 可在设置里关闭`，20/600，`rgba(253,243,216,.34)` | 2.59:1（非正文） | 说明来源与可关，同时是最容易被截图核对的一行 |

```js
// A 层：平铺水印（画在「背景之后、插画/纸面之前」，只在绒布上显现）
if (WATERMARK) {
  ctx.save();
  ctx.translate(540, 720); ctx.rotate(-Math.PI / 4); ctx.translate(-540, -720);
  ctx.fillStyle = 'rgba(253,243,216,.05)'; ctx.font = `600 20px ${F}`;
  for (let y = -400; y < 1800; y += 320)
    for (let x = -400; x < 1500; x += 420) ctx.fillText('韭菜之王', x, y);
  ctx.restore();
}
```

**三条硬规则**
1. **绘制顺序**：A 层夹在「背景之后、插画/纸面之前」——于是它**只在绒布上显现**，
   T2 的奶油碑面、T4 的小票、T5 的插画都会自动盖住它。这既是「轻量不挡主体」的实现方式，
   也顺手解决了「账单上不许出现斜字」的问题（纸面一盖就没了），不需要额外判断条件。
2. **不写绝对日期**：卡片会被存很久再转，`2026-11` 会显旧。与 ux `share-flow.md` 一致——
   时间信息一律用相对量（「第 N 天」）。编号 `结局 No.06` 取 `END[name].no`（1–32，**写死、只追加不重排**，与 ux `share-flow.md` 的 scene 编号同一套），不算日期、且是防伪点。
3. **开关**：`WATERMARK = true` 默认开；设为 `false` 时**A、B 两层一起跳过**，
   除这两层外画面必须**逐像素不变**（验收 §9 有这一条）——不许因为关水印改了布局。
   **小程序码不随水印关闭**（它不是水印，是分享入口）。

## 4. 五套模板

> 每个模板给：结构、逐块坐标表、允许字数上限、**避免什么**。
> 表里的 `y` 是**块顶**（= DOM 里 `top` 的语义）。canvas 用 `textBaseline='middle'` 时，
> `y_中线 = y_块顶 + 行高×字号 / 2`；所有换算好的中线值在 **`design/share-card-canvas.md`** 里，

> 样张 `.png` 已按此对齐，改文案不改坐标。

#### 4.5.2 压暗层（决定文字能不能读，参数不许改）

| 项 | 值 |
|---|---|
| 渐变 | `createLinearGradient(0, 400, 0, 1040)` |
| stops | `0 → rgba(12,43,30,0)` / `.38 → rgba(12,43,30,.45)` / `.78 → rgba(12,43,30,.88)` / `1 → rgba(12,43,30,.98)` |
| 覆盖 | `fillRect(0, 400, 1080, 640)` |

## 5. 文字折行与截断（不许缩字凑）

| 场景 | 规则 |
|---|---|
| quote 超行 | 按**句号/感叹号/问号**切句，从后往前删整句，删到 ≤ 上限行数；末尾补 `…`（省略号也算 1 字宽） |
| **quote 正好 2 行** | **均衡断行**：在所有标点处试断，选「两行字数差最小」且「后行不短于前行 40%」的那个断点（样张 T2：`……变少的，` ／ `少到你自己都习惯了。`）。canvas 实现：`wrap()` 得到候选，取平衡最好的一组；**禁止让第二行只剩 2~4 字**（读起来像被截断） |
| 只删了半句 | 删到该句的最后一个逗号，加 `…`；不出现「半个词」 |
| 结局名超宽 | 按 §4.x 的字号降级（200→168→144→120），**降到 120 仍超宽才截断**（32 个结局最长 5 字，正常不会触发） |
| 数字过长 | `¥` 后整数部分允许 6 位（含逗号 9 字符）；再长改「万」单位（`¥10.2 万`），**不缩字号** |
| emoji 缺失 | 用一个 24px 的空圆占位，**不许画 X**（画 X 会读作「错误」） |

## 6. 元素库（可复用 · canvas 画法）

### 6.1 印章（斜角双线框）

```js
// 参数：x,y,w,h,rot,fill,ink,text,fs
function seal(ctx, x, y, w, h, rot, fill, ink, text, fs) {
  ctx.save();
  ctx.translate(x + w / 2, y + h / 2);
  ctx.rotate(rot * Math.PI / 180);
  ctx.shadowColor = 'rgba(0,0,0,.22)'; ctx.shadowOffsetY = 8; ctx.shadowBlur = 0;

  // ① 章体（圆角 10）
  roundRect(ctx, -w / 2, -h / 2, w, h, 10);
  ctx.fillStyle = fill; ctx.fill();
  ctx.shadowColor = 'transparent';

  // ② 外框：4px，内缩 12（离章体边 12，视觉上「留红边」）
  ctx.strokeStyle = ink; ctx.lineWidth = 4;
  roundRect(ctx, -w / 2 + 12, -h / 2 + 12, w - 24, h - 24, 6); ctx.stroke();

  // ③ 内框：1.5px，内缩 28（双线框 = 防伪感）
  ctx.lineWidth = 1.5;
  roundRect(ctx, -w / 2 + 28, -h / 2 + 28, w - 56, h - 56, 4); ctx.stroke();

  // ④ 磨砂：沿边缘撒 40 个 2~5px 的章体色斑（模拟印泥不匀，破「矢量塑料感」）
  for (let i = 0; i < 40; i++) {
    const a = rnd(i) * Math.PI * 2, r = 0.5 + rnd(i + 99) * 0.5;
    ctx.beginPath();
    ctx.arc(Math.cos(a) * w / 2 * r, Math.sin(a) * h / 2 * r, 1 + rnd(i + 7) * 2, 0, 7);
    ctx.fillStyle = 'rgba(0,0,0,.10)'; ctx.fill();
  }

  // ⑤ 文字（字距自己算）
  ctx.fillStyle = ink; ctx.font = `900 ${fs}px ${F}`;
  ctx.textBaseline = 'middle';
  fillCenter(ctx, text, 0, 4, fs * 0.18);   // +4 补偿中文字面重心偏上
  ctx.restore();
}
```

**旋转包围盒**（保证印章不压别的块）：`W' = w·|cos θ| + h·|sin θ|`，`H' = w·|sin θ| + h·|cos θ|`。
T3 大印 720×300 @7° → 包围盒 **750 × 322**；上下各留 ≥24 才不压字，所以 y 224 起、引文从 620 起是安全的。

### 6.2 票据锯齿边

```js
// 底边锯齿：齿宽 57.5（920 / 16），齿高 22，向下凸
function teeth(ctx, x, y, w, h, n) {
  const tw = w / n;
  ctx.beginPath();
  ctx.moveTo(x, y);
  for (let i = 0; i < n; i++) {
    ctx.lineTo(x + tw * i + tw / 2, y + h);   // 尖朝下
    ctx.lineTo(x + tw * (i + 1), y);
  }
  ctx.closePath();
  ctx.fillStyle = '#fdf6e1'; ctx.fill();
  ctx.strokeStyle = '#241a0e'; ctx.lineWidth = 3; ctx.stroke();
}
// 用法：纸体画到 y=1098，再 teeth(ctx, 96, 1098, 920, 22, 16)
// 注意：齿数与纸宽绑定（16 齿 @920 = 57.5/齿），换纸张宽度必须重算，否则齿距不整
```

### 6.3 标签角（角标）

```js
// 左上角直角三角形标签（T1 的「活法／死法」也可用）：不是 clip-path，是三角路径
function cornerTag(ctx, x, y, size, fill, ink, text) {
  ctx.beginPath();
  ctx.moveTo(x, y); ctx.lineTo(x + size, y); ctx.lineTo(x, y + size); ctx.closePath();
  ctx.fillStyle = fill; ctx.fill();
  ctx.strokeStyle = ink; ctx.lineWidth = 3; ctx.stroke();   // 只需描斜边也可，见下
  // 字沿 45° 排：translate + rotate(-45deg) 后水平写
  ctx.save();
  ctx.translate(x + size * 0.19, y + size * 0.19); ctx.rotate(-Math.PI / 4);
  ctx.fillStyle = ink; ctx.font = `800 24px ${F}`; ctx.fillText(text, 0, 0);
  ctx.restore();
}
```

> 三角标签**只用在 T1 右上 / 左上角**，一卡最多 1 个（两个角标就变成促销贴纸）。

### 6.4 涨跌三角

```js
function tri(ctx, x, y, size, up, color) {          // up=true 朝上
  ctx.beginPath();
  if (up) { ctx.moveTo(x, y); ctx.lineTo(x + size, y); ctx.lineTo(x + size / 2, y - size * 0.86); }
  else    { ctx.moveTo(x, y - size * 0.86); ctx.lineTo(x + size, y - size * 0.86); ctx.lineTo(x + size / 2, y); }
  ctx.closePath(); ctx.fillStyle = color; ctx.fill();
}
// ▲ 涨 #ff6b5e（绒布上）/ #c9302a（纸上）；▼ 跌 #4fbf82 / #157a44
// 只在 T1 / T4 的数据值前用，尺寸 26；一个数字只配一个三角
```

**编码三重性**：形状（三角）+ 符号（`+`/`−`）+ 颜色，三者同现；缺任意一项都不合格（色弱可读）。

### 6.5 格子底纹

见 §3.1（60px 网格，`rgba(253,243,216,.045)`，1px）。
纸上版本：`rgba(43,31,18,.05)`。**网格只在绒布上用**，纸上用网格会像草稿纸。

### 6.6 噪点

见 §3.1（1200 点，固定种子）。
纸上版本：`rgba(43,31,18,.035)`，600 点——纸的噪点要比绒布**更少更淡**，
否则小票看起来像打印坏的。

## 8. 小程序落地（红线）

### 8.1 按 dpr 缩放（一句话）

**canvas 的 CSS 尺寸设成 `1080×1440`（1 绘图单位 = 1 CSS px），backing store 设成 `1080×dpr'` / `1440×dpr'`（`dpr' = min(2, pixelRatio)`），
`ctx.scale(dpr', dpr')` 之后全部用本文的 1080 基准坐标作画，导出 `wx.canvasToTempFilePath({ width:1080, height:1440, destWidth:1080, destHeight:1440 })`——
dpr 只影响笔触精度，不改变任何规格数值。**

> **dpr 必须封顶 2（2026-11-11 采纳 ux `share-flow.md` §2.3.1 的修正）**：dpr=3 时 backing store 是
> 3240×4320，RGBA 约 **56MB**，低端安卓直接 OOM 闪退；封到 2 → 2160×2880 ≈ **24.8MB**。
> 导出仍是 1080×1440，2 倍过采样足够（没人把分享图放到 300% 数 1px 描边）。

```js
const q = wx.createSelectorQuery().in(this);
q.select('#shareCv').fields({ node: true, size: true }).exec(res => {
  const cv = res[0].node, ctx = cv.getContext('2d');
  const dpr = Math.min(2, wx.getWindowInfo().pixelRatio);   // ← 封顶 2，见上
  cv.width = 1080 * dpr; cv.height = 1440 * dpr;            // backing store（最大 2160×2880）
  // CSS 尺寸由 WXSS 写死 width:1080px; height:1440px（离屏定位），保证 1 单位 = 1 CSS px
  ctx.scale(dpr, dpr);                            // ← 之后一律 1080 基准
  drawShareCard(ctx, data);                       // 本文所有坐标直接可用
  wx.canvasToTempFilePath({
    canvas: cv, x: 0, y: 0, width: 1080, height: 1440,
    destWidth: 1080, destHeight: 1440, fileType: 'png', quality: 1,
    success: r => this.setData({ shareImg: r.tempFilePath }),
  });
});
```

### 8.2 其他

| 项 | 规定 |
|---|---|
| 离屏画布 | 用 `<canvas type="2d" id="shareCv" style="position:fixed;left:-9999px">`（**不要**塞进可见区域再 `canvasToTempFilePath`，会闪） |
| 字体 | 只用系统字体栈；**不加载自定义字体**（`wx.loadFontFace` 首次渲染会掉字，且分享是即时行为） |
| 图片资源 | 插画、码图先 `img.onload` 再画；全部 load 完才 `canvasToTempFilePath`（否则 T5 出空白） |
| 尺寸上限 | 1080×1440 PNG 通常 300~500KB；若 >600KB，T5 走 `fileType:'jpg'`，其余保持 PNG |
| 缓存 | 同一局（同 `endName + 数据`）只生成一次，结果缓存到 `wx.env.USER_DATA_PATH`；重开结局页直接复用 |
| 首帧 | **后台预生成**（与 ux `share-flow.md` §2.3 一致）：结局页 `onShow` 后 **1200ms** 静默画一次，按 `endName \| day \| net \| trades \| tpl` 缓存；玩家点「存一张」时命中缓存，0 等待。只有 `tier==='full'`（首次解锁 / 当天首次结局）预生成。「生成中…」降级为**兜底态**（缓存未命中才出现），正常路径看不到 |
| 禁止 | `ctx.filter`（小程序不支持）、`Path2D`（部分机型缺失）、`ctx.createPattern(新 Image)`（时序坑）。渐变/shadow/measureText 是安全的 |
| 保存相册 | `canvasToTempFilePath` 后 `wx.saveImageToPhotosAlbum`，授权失败给「长按图片保存」的降级提示 |

### 8.3 CSS 特性 → canvas 对照表（施工时逐条核对）

| 想用（禁止） | canvas 等价 |
|---|---|
| `backdrop-filter: blur()` | 直接半透明实色层（`rgba`） |
| `clip-path` / `mask` | `ctx.save(); ctx.beginPath(); ctx.rect/arc; ctx.clip(); …; ctx.restore()` |
| `linear-gradient` / `radial-gradient` | `createLinearGradient` / `createRadialGradient`（角度/位置手算） |
| `box-shadow` 硬投影 | `shadowColor + shadowOffsetY + shadowBlur:0` |
| `letter-spacing` | 逐字 `fillText` + `measureText`（§3.3） |
| `text-align: center` | `ctx.textAlign='center'`（**有 letter-spacing 时不能用**，要用 `fillCenter`） |
| `border-radius` | `arcTo` 手写 `roundRect` |
| `SVG` 图标 | 路径 `moveTo/lineTo/arc` 或导出的 base64 图 |
| `overflow: hidden` 裁切 | `ctx.clip()` |
| `flex` 布局 | **没有**：全部绝对坐标（本文档每一块都给死了 y） |
