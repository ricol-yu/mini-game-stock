# 配角阵容 · 一个高频同事 + 两个一次性角色

> 2026-11-11 初稿 / **2026-11-13 按最终档位改定** · 视觉架构师。读者：写卡的人、出图的人、前端。
> **定位**：这三个 `whoId` **都不进支线**（B 档唯一支线是 `nidepiao`，见 `design/characters.md`）。
> 但他们的**配额不同**：小王是 A 档普通高频（≤5 次/局），张阿姨与司机是 C 档一次性（≤1 次/局）。
>
> 一句话区别：
> - **常驻**靠「他会变」（弧线 / stage / 复现）。
> - **配角**靠「他不变」（每次出现都是同一个样子、同一种口气），**变的是你**。
>
> 关联：`design/characters-visual.md`（视觉数值：配色 / emoji / 构图 / 角色卡组件）、
> `share-card-spec.md`（分享卡上不出现角色名）、`art-prompts.md` §1.1（构图句接在全局风格句后）。
> **本文只写人设与用法，不改任何现有卡的文案。**

---

## 0. 档位与配额（2026-11-13 拍板，覆盖初稿的「三人一律 ≤1 次」）

| 档 | 谁 | 配额 |
|---|---|---|
| **A 档 普通高频** | 老婆 `laopo`、老妈 `laoma`、**同事小王 `tongshi_xiaowang`** | **≤5 次/局、间隔 ≥6 张、第 3 天前不登场** |
| **B 档 唯一支线** | 你的票 `nidepiao` | 每局最多升 2 段（**无形象**，见 `characters-visual.md` §1） |
| **C 档 一次性** | 张阿姨 `zhangayi`、出租车司机 `taxi` | **≤1 次/局** |

**小王为什么是 A 档不是 C 档**：他有 3 张卡（问你买啥 / 借 3,000 补仓 / 表哥的消息），全是职场场景，
「同事工作日天天见」不违和。把他限成 ≤1 次，另外两张就永远是抽不到的死卡——等于白删两个内容。
而且 A 档「**不改数据**」这条，也指向不要给他新增一次性闸门：**不加 `tier`、不加 `stage`、不扩卡**。

## 0.1 使用规则（先立规矩，再写人）

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **配额分档**：C 档（张阿姨 / 司机）**单局 ≤1 次**；A 档小王 **≤5 次/局、间隔 ≥6 张、第 3 天前不登场** | C 档靠「突然出现」才有杀伤力，第二次就变成常驻；而小王是同事，天天见才不违和，且他有 3 张卡要轮转 |
| 2 | **都不进支线位**：不加 `tier` / `stage`、不进 `END`、不被 `nidepiao` 支线消费 | 支线位是给「会变的人」的。混进去会让 B 档的弧线失焦，也会让配额无法校验 |
| 3 | **不复用口头禅，且同一张卡同局不重复**（小王会出现多次，但那几次必须是三张**不同**的卡） | 同一张卡重复 = 「这游戏没卡了」；跨局重复 = 「这个人就是这样说话的」 |
| 4 | **不设 `av` 第二版**：一个角色一个 emoji，全线统一（👔 / 🧶 / 🚕） | 视觉识别全靠那一个符号，换一次就断了 |
| 5 | **不给他们「后来」**：不写「小王升职了」「张阿姨搬走了」「司机不炒了」 | 配角的力量在于**没有下文**。下文是支线的事 |
| 6 | **数值方向：都是社会/心态的账，不是钱的账** | 他们卖的是关系压力，不是收益。钱只作杠杆（借 3,000 换 12 点社会） |

> 校验建议（写进 `tools/validate-cards.js`）：
> - C 档两个 `whoId`：跑一局统计「同局出现次数 >1」应为 0；`tier`/`stage` 必须为空。
> - 小王：`tier`/`stage` 为空、卡池不新增；同局出现 ≤5、任意两张之间隔 ≥6 张；第 3 天前不出现。
> - 三个 `whoId` 的卡 `when` 里**不许出现 `did:`**（那是支线的分叉语法）——**唯一例外**是司机的 `mkt_taxi_02`（见 §3.7）。

### 闸门挂哪儿（2026-11-13 补记 · 防前端挂错位置）

> 这条是上一轮「闸门挂错抽屉」的同类坑，写在这儿留底。

1. **票的 6 张卡横跨两种抽屉，不是一种**：`isChain(c)` 的实现是 `w.indexOf("did:") >= 0 || w.indexOf("seen:") >= 0`（`prototype.html:2018`），
   而段 3 那两张 `piao_silent_01/02` 的 `when` 里特意绑了段 2 四张卡的 `did:` 长 OR——所以**它们被判成链卡**。

   | 卡 | `isChain` | 走的抽屉 |
   |---|---|---|
   | `piao_voice_01/02`（段 1，无 `did:`） | false | `bagFind` |
   | `piao_voice_03/04`（段 2，无 `did:`） | false | `bagFind` |
   | `piao_silent_01/02`（段 3，有 `did:` 长 OR） | **true** | **`bagFindChain`** |

2. 因此配额闸门**必须同时挂在 `bagFind` 和 `bagFindChain` 的候选循环第一行**——
   理由不是「全走普通抽屉」，而是**两种抽屉都有卡会走**；只挂 `bagFindChain` 会漏掉段 1/2，只挂 `bagFind` 会漏掉段 3。
3. 反过来，链卡不能被闸门误杀：`mkt_taxi_02` 依赖 `did:mkt_bull_taxi_01.r`，若按「≤1 次」无差别拦，`mkt_bull_taxi_01` 出过之后 `_onceCnt.taxi = 1`，**这张卡就永远出不来**。
   **豁免写法：候选循环第一行加 `!isChain(c)`，并让链算同一次**（即同一条 `did` 链只占 1 个配额）。
   **实现以 `docs/design/share-flow.md` §4.1 为准**（`if (c.wid && C_ONCE[c.wid] && !isChain(c) && strict)`）——本文不另立一份写法，避免口径漂移。
4. **`bagFindChain` 有 `_lastWasChain` 隔天限制**（昨天插过队，今天必须先出普通卡），所以段 3 的**实际可出天数会晚于理论值**。
   **这是预期行为，不许为了让它「准时」去解这条限制**——它保护的是「每天都有普通卡」的节奏，比支线准点重要。

## 1. 同事小王 `tongshi_xiaowang`

### 1.1 一句话
**他是公司里唯一一个真的相信你能带他赚钱的人。**

| 项 | 内容 |
|---|---|
| 称呼 | 玩家叫他「小王」；他叫玩家 **「哥」**（永远不改——叫法一变成"你"，这条就变成支线了） |
| 年龄 | 26，入职一年半，比你晚来 |
| 关系 | 同一个组，工位在你斜后方，隔着一块半高挡板 |
| 现状 | 3 张：`work_tip_01` 表哥消息 / `work_follower_01` 问你买啥 / `work_xiaowang_02` 借 3,000 补仓 |

### 1.2 外貌一句话
**格子衬衫永远扎在裤子里，工位抽屉里塞着半袋没吃完的坚果，手机屏保是女朋友。**

### 1.3 说话方式

| 维度 | 规定 |
|---|---|
| 口头禅 | 「哥，你觉得呢？」·「我就跟着你买一点」·「真的假的？」 |
| 句子长度 | **短。6~14 字，一句一问**。他不敢下判断，所以话都带问号 |
| 爱用什么词 | 跟 · 学 · 也 · 试试 · 小仓位 · 稳一点 · 「我老婆说」 |
| 绝不说什么 | ❌「你不懂」 ❌「我早说了」 ❌ 任何嘲讽、任何「我比你懂」。**他永远不指责你**——仰视的人没有资格 |
| 语气 | 试探、压低声音、带一点点讨好。永远在办公室里、隔着挡板说话 |

> 写卡诀窍：他的**每句台词都应该是一个请求**（要方向 / 要跟着买 / 要借钱），不是判断。
> 他不提供信息，他提供压力。

### 1.4 视觉标识

| 项 | 值 |
|---|---|
| 主色 | `--sc-wang` **#5aa9e6**（冷蓝：还没被市场污染的清亮） |
| 头像 emoji | **👔**（物件语言：一条领带 = 一个刚上班的人。现存 `work_tip_01` 是 👨‍💼，需统一） |
| 头像底 | `rgba(90,169,230,.18)` |
| 构图（若该卡需要图） | 接 `art-prompts.md §1.1` 后加：**【本张】办公室工位区的半高隔断后，一个年轻人探出上半身，右手举着手机、屏幕朝画面外（屏上只有抽象色块与曲线，无文字），另一只手撑着挡板；身后是虚化的整排工位；右下露出一只马克杯和半袋坚果。脸在画面上方 28% 高度、身体偏右 1/3，中央留低对比空间。** |
| 镜头 | **略低、他前倾**——要拍出「仰」，不是平视 |

### 1.5 台词基调（3 句示例，非具体卡）

1. 「哥，你那个……后来赚了吗？」 —— 问的是结果，不是方法。
2. 「我工资就这些，你说买多少我就买多少。」 —— 把决策权整个推给你。
3. 「我老婆问我最近在忙啥，我说跟同事学点东西。」 —— 他已经在家里给这件事编了个体面的名字。

### 1.6 最狠的那一句

> **「哥，我把房贷的钱也挪出来了，你说买啥？」**

狠在哪：他把**身家**交给你，而且是笑着交的。这一句之后，玩家每次操作都会想起他。

### 1.7 A 档普通高频的用法

- **放在哪**：全周期都可能（职场场景不看牛熊），但**第 3 天前不登场**——先让玩家自己犯一次错，他的话才有分量。
- **配额**：**≤5 次/局，任意两次之间隔 ≥6 张**。三张卡轮转，不许同一张重复。
- **机制落点**：给一个「可以把他拖下水」的选项（右滑）和一个「主动切断关系」的选项（左滑，社会 −）。
  两边都不轻松才是这张卡。
- **最狠的那一句只出现一次**：「哥，我把房贷的钱也挪出来了，你说买啥？」——放在他的**最后一张**（或玩家已连赢 3 次之后）。
  既然他是高频，这一句更要省着用：说两次就不再是钉子，而是口头禅。
- 出错时的表现：**永远不指责你**。他下次出现还是那句「哥，你觉得呢？」——这就是 A 档的处理方式。

## 2. 张阿姨 `zhangayi`

### 2.1 一句话
**她真的希望你发财，她只是不知道自己手里传的是什么。**

| 项 | 内容 |
|---|---|
| 称呼 | 你叫她「张阿姨」；她叫你 **「小伙子」**（永远不叫名字——她记不住，也不需要记住） |
| 年龄 | 58，退休返聘，在小区门口/菜市场有个摊位，卖毛线也卖菜 |
| 关系 | 楼下邻居、菜市场熟人、**你妈的牌友**——这是她不请自来的底气 |
| 现状 | 2 张：`soc_banquet_01` 寿宴随礼 / `soc_insider_01` 内部渠道（3,000 进门费） |

### 2.2 外貌一句话
**烫过的卷发用一根黑色发夹别住，围裙口袋里永远塞着两部手机（一部看行情，一部接电话）。**

### 2.3 说话方式

| 维度 | 规定 |
|---|---|
| 口头禅 | 「我跟你说」·「真的，我侄女婿就在里头」·「不骗你」 |
| 句子长度 | **中长，一口气 20~30 字，用逗号串起来，几乎不用句号**。她说话不换气 |
| 爱用什么词 | 内部 · 渠道 · 名额 · 稳 · 保底 · 「人家都说」·「我给你留了一个」 |
| 绝不说什么 | ❌ 具体数字（她记不住，也不觉得重要） ❌「风险」这个词 ❌ 承认自己不懂 |
| 语气 | 热络、压低声音、把「消息」当礼物递给你。**她永远在做好事** |

> 写卡诀窍：她给的信息**必须有一半是真的**（「我侄女婿在券商」），另一半无法核实（「内部渠道」）。
> 她不是骗子，是**放大器**。她从不因结果道歉，因为从头到尾没有恶意——这也是玩家最没法发火的地方。

### 2.4 视觉标识

| 项 | 值 |
|---|---|
| 主色 | `--sc-zhang` **#d9733c**（砖橙：菜场、毛线、暖得不讲道理） |
| 头像 emoji | **🧶**（毛线——她的摊位、她的动作；现存 `soc_banquet_01` 用 🏘 是楼栋、不指人，需统一） |
| 头像底 | `rgba(217,115,60,.18)` |
| 构图 | **【本张】菜市场摊位前的中景，一个卷发的中年女人坐在塑料凳上，手上还在织毛线，抬头跟画面外说话；摊上两筐菜与几团毛线，手腕上挂着塑料袋；背景虚化的市场过道与暖白灯管；中央偏右留低对比空间。** |
| 镜头 | 平视略高（她坐着、你站着），人物占图宽 1/3 偏右 |

### 2.5 台词基调（3 句示例）

1. 「我跟你说，这个名额就剩两个了，我特意给你留的，你别嫌阿姨多事。」
2. 「人家都说要涨到年底，我侄女婿就在里头上班，他能骗我？」
3. 「你先少拿点试试，赚了再添，谁一开始不是这样，阿姨当年也是这么过来的。」

### 2.6 最狠的那一句

> **「钱我先替你垫上了，赚了再还我。」**

狠在哪：她把钱**先花了**，于是「拒绝」这个动作消失了——你不是在选择，你是在还人情。

### 2.7 一次性卡的用法
- **放在哪**：牛市中期 + 玩家社会值偏高时（她只找"熟人"）。
- **机制落点**：这一句之后**取消左滑的"干净退出"**——至少让拒绝也要付社会代价（−6 起）。
  她真正的杀伤力不在钱上，在"你没法怪她"。
- **出现频率**：单局 ≤1。第二张卡（寿宴/垫钱）与她同局出现时，**必须隔 ≥10 天**。

### 3.5 台词基调（3 句示例）

1. 「上个月我把工作辞了，现在全职，跑车就是散心，一天两单够了。」
2. 「兄弟你一个月挣多少？我上周一天就把车份儿挣回来了，真的，就一天。」
3. 「我老婆还不知道，等我这一波做完，我就跟她讲，到时候让她也别上班了。」

### 3.6 最狠的那一句

> **「我老婆还不知道。」**

狠在哪：他不是在炫耀，是在**给自己找一个还没爆炸的理由**。而这句一说出口，玩家就懂了——他回不去了。

### 3.7 一次性卡的用法
- **放在哪**：牛市（`has:bull`）中后段，玩家风险 ≥55 时（这时他说的话最像"同盟"）。
- **机制落点**：给「跟一手小的」（风险 +9、心态 −2）与「祝你好运」（社会 −3、心态 +3）。
  他的卡永远不该给"稳赚"的感觉——跟他就是加风险。
- **出现频率**：单局 ≤1。现有 `mkt_taxi_02` 依赖 `did:mkt_bull_taxi_01.r`，属**同一条链**，是"配角链"的孤例。
  **已定口径**：不改卡，闸门加 **`!isChain(c)` 豁免**，并且**一条 `did` 链只占 1 个配额**（「链算同一次」）。
  闸门位置见 §0.1「闸门挂哪儿」——`bagFind` 与 `bagFindChain` 的候选循环第一行都要挂。

## 4. 三个人的关系（别让他们变成同一个人）

| | 他凭什么劝你 | 他失去什么 | 玩家对他的真实情绪 |
|---|---|---|---|
| 小王 | 他相信你 | 他的房贷 | 愧疚（我害了他） |
| 张阿姨 | 她喜欢你 | 她的钱、你的人情 | 窒息（我怪不了她） |
| 司机 | 他需要同类 | 他的工作、他的婚姻 | 恐慌（我会不会变成他） |

> 三个人的可怕之处**都在于他们不坏**。写卡时只要往「坏人」方向偏一点（算计、嘲讽、看笑话），
> 这张卡就废了——玩家会开始讨厌他，讨厌的人不用被记住。
