# UI v2 · 桌游牌局风（C 版）设计规格

> 2026-11 定稿。方向：**强游戏感桌游风**（Reigns × Slay the Spire 的卡面质感，不融 A/B）。
> 本文是施工依据：所有数值可直接抄进 `prototype.html` 的 `:root` 与类名，类名与现有原型对齐，
> 新增类统一 `u2-` 前缀。样张见 `design/ui-v2-demo.html` / `.png`。
>
> **设计原则（4 条，越界即返工）**
> 1. **手感优先，但克制**：厚卡、粗描边、硬投影给"牌在手里"的重量；不加大面积高饱和渐变、
>    不做霓虹发光，避免俗气。质感只靠「粗描边 + 双层硬投影 + 渐变 + 纹理」四件套。
> 2. **文字永远赢**：卡面正文自然高度，人物图区吃剩余空间；图再大不许压字、不许挤字。
> 3. **一屏三层**：账（行情区）／命（HUD）／事（卡牌）。三层各自有底色，
>    靠"奶油纸 vs 深绿绒布"的明度差分层，不靠投影堆叠。
> 4. **数字是主角**：钱、涨跌、天数一律 tabular-nums + 800/900 字重；界面其余部分退到背景里。

## 2. 布局与栅格（375 设计基准 / 真机按 ux `ui-adaptation.md`）

> **与美术规格的测量对账（2026-11-03）**：`art-asset-spec §0` 的「375 屏卡面内宽 274」量的是 344px 开发框；
> 真机 clean 模式的卡内宽是 **309**（375 − 32 内容 inset − 34 卡内距）。本版所有横向数值按 **309** 出，
> 图区导出尺寸相应重算（见 §5）。demo 已按 309 对齐（`.stage` 左右 16）。

### 2.1 垂直分配（390×844 基准机，自定义导航 + 安全区）

`navH = statusBarH + (胶囊 top − statusBarH) × 2 + 胶囊高`；375 档 60、390 档 87、430 档 87~94。

| 区块 | 高度 | 说明 |
|---|---|---|
| 自定义导航 | 87（390 档） | 状态栏占位 + 40 内容行（标题居中，右侧 78×30 胶囊位由微信绘制） |
| HUD 四条命 | 48 | `padding: 0 12px`，内部图标行 46 |
| 状态胶囊行 | 26 | `padding: 4px 16px 0`，可换行 / 横滚 |
| 行情区 mkt | **158** | 面板本体（含 3px 描边 6）。比 v1 的 112 高 46：描边 6 + 净值 24px 行 26 + 账目独立行 21 + 分时图 48 |
| 区块外边距 | 14 | mkt 上下 8 / 6 |
| 卡牌舞台 | 剩余 **465** | 左右 16，底 12 |
| 底部安全区 | 34 | `env(safe-area-inset-bottom)`，不写死 |

**卡区高度 = stage − 4（上 inset）− 16（下 inset，留给牌背露出）**；图区 = 卡高 − 6（3px 描边×2）− 24（卡内距）− 10（图与文字间距）− 正文（55 两行）。

| 机型 | stage | 卡高 | 图区（两行正文） |
|---|---|---|---|
| 320×568 SE1 | 250 | 230 | 135 → **触发 ux §1.5 降级**：tape **整块隐藏**（ux 新增 stage<270 一档，一次还回 46px）→ 终态 **stage 296 / 卡高 276 / 图区 181**；HUD 48 **不动**（HUD 档阈值压到 stage<230，此档不触发）、图区仍 ≥170 红线，**版式视觉无变化** |
| 375×667 SE2/3 | 349 | 329 | 234 |
| 390×844 基准 | 465 | 445 | **350** |
| 430×932 Pro Max | 546 | 526 | 431 |
| 812 原型框（无安全区） | 470 | 450 | 355 |

> ⚠️ **与 ux 高度表的差异**：`ui-adaptation.md §1.3` 记 390 档图区 402，是按 v1 行情区（112）算的；
> v2 行情区 158 让图区变成 **350**（−52）。仍在 170 红线以上、不需要降级，但那张表要按本节更新。
> 若要追回高度，唯一可动的是账目行（改回叠在分时图上，回收 21px）——不建议，分时图被字盖住更难受。

### 2.2 横向：底满、内容让

- 背景（含绒布渐变）**铺满到物理边缘含安全区**，内容才做 inset：`.page-bg{background:var(--u2-felt)}` 全屏，
  内容列 `max-width:480px; margin:0 auto`（折叠屏展开态封顶居中，不做双栏）。
- 内容列左右距边 **≥16px**：stage 16、mkt 16、HUD 12（图标居中分布不贴边）。
- 宽度 <360（仅 SE1）三处收紧：stage 16→12、mkt 16→10、卡内距 14→12。
- 一屏一列，不做多列；间距一律用 §1.3 阶梯值。**字号、1px 描边、阴影不随屏宽缩放**。

### 2.3 全屏画布色

小程序 `app.json` 的 `backgroundColorTop / Bottom` 必须与绒布渐变**外缘**同色 `#0c2b1e`，
否则上滑回弹时露出的系统底色（现配 `#0b3d2e`）和渐变外缘有明显色差，沉浸感当场破功。

## 3. 组件规格

### 3.1 自定义导航 `nav`

- 结构：`状态栏 44（空） + 标题行 40`，总高 84。
- 标题：`--u2-fs-title`，色 `--u2-on-felt`，字距 5px，居中；无下划线、无背景。
- 微信胶囊：右侧 `right:12px`，尺寸 78×30，圆角 15，描边 1px `--u2-felt-line`，
  底 `rgba(0,0,0,.20)`；内部两个占位圆点用 `--u2-on-felt-2`。
  **真机上胶囊由微信绘制，代码里这块只是占位**（`wx.getMenuButtonBoundingClientRect` 对齐）。
- 左侧不放返回键（游戏内无返回）；如需暂停键，用 32×32 描边方钮，与本行垂直居中。

### 3.2 HUD 四条命（王权式，不许改成 label+条+数值）

- 一行四个，`justify-content: space-around`，单项 **34×32**，图标本体 **28×28**（viewBox 24）。
- 图标造型（沿用现有 path，不改形）：
  - 精力＝闪电、心态＝心、风险＝三角＋感叹号、社会＝双人。
- **填充机制（小程序可行版，不用 clip-path / mask）**：
  ```
  .vit-i            相对定位，34×32
   ├ .u2-vit-slot   absolute inset:0，灰底图标（rgba(0,0,0,.22)）
   ├ .u2-vit-fill   absolute left/right:0 bottom:0，height = 数值%（0~100）
   │   └ .u2-vit-ico  absolute bottom:0，34×32 的**彩色整图**（overflow:hidden 自然裁出下半截）
   └ .u2-vit-out    absolute inset:0，只有描边（stroke 2.2 `--u2-on-felt`）
  ```
  外层 `.u2-vit-fill` 的高度就是液面——改高度即改数值，天然带 `--u2-t-slow` 过渡。
- 描边：2.2px `#f7ecc9`（绒布上必须亮色描边，深色描边会糊）；风险三角的感叹号用 `--u2-edge`。
- 填充色：精力 `#ffcf3f` / 心态 `#ff5d52` / 风险 `#ff9426` / 社会 `#58b6ff`。
- 预警：风险 >68、心态 <22 或 >88、精力 <25、社会 <22 → 整图标 `--u2-t-blink` 呼吸。
- 飘字：图标上方 −22px，`--u2-fs-num`，增量 `--u2-down`（+）、减量 `--u2-up`(−)；
  0%↗8px 淡入 → 18% 到位 → 100% 上飘 17px 淡出，全程 1150ms。
- **触达**：视觉 34×32，**点击热区补到 44×44**（透明外扩，图标本身不放大）。
- **数值入口**：具体数值不常驻，`tap` 图标弹出 tip（同一时刻最多一个，点空白全关；桌面保留 hover）；
  `tip` 容器 `pointer-events:none`，内容层可点。
- **无图态**：不存在（图标是矢量，无素材依赖）。

### 3.3 状态胶囊 `chip`

| 态 | 底 | 描边 | 文字 | 场景 |
|---|---|---|---|---|
| 普通 | `#fdf3d8` | 1.5px `rgba(43,31,18,.28)` | `--u2-ink-2` | 天数、利息等中性信息 |
| 热度 `hot` | `#ffe9bf` | 1.5px `#e0a53a` | `#8a5a12` | 牛市、涨停、添加丁等"好事" |
| 欠款 `due` | `--u2-due-bg` | 2px `--u2-due-line` | `--u2-due-ink` | 「🏠 1 天后交钱 ¥6,900」 |
| 老赖 `ll` | 同 due + 红标 | 红标：`#c9302a` 底、白字、9px、圆角 8、`padding:1px 5px` | — | 逾期未还 |

- 高 22，圆角 12，内距 `3px 9px`，字号 `--u2-fs-cap`；数字用 `<b>` 800 字重。
- 多个胶囊间距 5，最多两行，超出横向滚动（`overflow-x:auto`，隐藏滚动条）。

### 3.4 行情区 `mkt`

面板：底 `--u2-card`，描边 **3px** `--u2-edge`，圆角 14，内距 `10px 12px 9px`，
阴影 `--u2-sh-hard-sm` + 柔影。

1. **净值行**：`¥26,153` 用 `--u2-fs-hero`（24/900）。右侧收益率 `+30.8%`（`--u2-fs-num`，红/绿）。
   - 飘字 `+¥5,670`：绝对定位挂在净值右侧 +8px，`--u2-fs-num`，不占布局（不许推挤右侧收益率），
     入场 2900ms：6% 淡入、84% 开始上飘 8px 淡出。
2. **三段资金条**：高 7，槽底 `--u2-card-2`，圆角 4，外描 1.5px `rgba(43,31,18,.35)`。
   - 现金段：渐变 `#ffc63f → #f2a51e`；持仓段：渐变 `#ff6b5e → #e23c30`；
     负债段（右起）：斜纹 `repeating-linear-gradient(-45deg,#c9302a 0 3px,#ffb3ab 3px 6px)`。
   - 宽度 = 各段金额 / 净值；切换 550ms。
   - **负债 ≥ 信用额度 80%**：负债段叠加 `--u2-t-breathe` 呼吸。
3. **分时图 `tape`**：高 48，底 `#fff9e8`，描边 2px `#2b1f12`，圆角 9。
   - 昨收虚线：1px dashed `#c9b98c`，位于高度 72% 处。
   - 线：2.5px `--u2-up`（涨）/ `--u2-down`（跌），线下降线色 13% 填充。
   - 角标「今 +1.5%」：右上 3/4 处，`--u2-fs-tag`，底 `--u2-up-deep` 白字，圆角 6。
     角标与线终点必须保持 ≥8px 间距（线的右端压到 y≈30% 高度，不顶到角标）。
   - 小程序：tape 用 `canvas 2d` 画（或预渲染 image），不用 SVG。
4. **日期行**：`--u2-fs-meta`，色 `--u2-ink-3`，`第 4 天 · 现金 ¥9,060 · 持仓 ¥17,093`。
5. **今日账目轮播 `ledg`**：独立 **16px 行**，夹在资金条与分时图之间（不压净值、不压资金条、不压分时线），
   单行居中，10.5px / 700；每笔 920ms（弹入→停留→上飘），红＝进账、绿＝出账、`--u2-ink-3` 转账。
   超过 7 笔合并小额为「其他」，一圈 ≤8 秒。多花 21px 换分时图 100% 不被字盖，值。
6. **高度 158**（含 3px 描边）：比 v1 的 112 高 46，图区因此从 ux 表的 402 降到 **350**（见 §2.1），
   仍在 170 红线上。这 46px 花在「24px 净值行 + 独立账目行 21 + 粗描边 6」上，值。
7. **涨跌三重编码**：净值、飘字、收益率、分时角标全部带 `▲/▼`；`0.0%` 用 `—` 灰，不带三角。

### 3.5 卡牌 `.card`

- 舞台 `.stage`：`margin: 0 16px 12px`（内容 inset ≥16，见 §2.2），`position:relative`，`min-height:150`。
- 主卡：`absolute inset: 4px 0 16px`，底 `--u2-card`，**3px** `--u2-edge`，圆角 16，
  内距 `12px 14px 12px`，阴影 `--u2-sh-hard` + `--u2-sh-soft`。
- **牌背垫层 2 层**（只暗示"还有牌"，绝不透露内容）：
  | 层 | transform | 不透明度 | 底 |
  |---|---|---|---|

### 5.2 三层结构（自下而上）

1. **场景层** `u2-art-scene`：铺满，`object-fit:cover`。无场景图时用同色系渐变占位
   （暖橙 `linear-gradient(180deg,#ffe3a0,#ff9e58)` 或按 tag 分牛市红调 / 熊市绿调 / 生活灰调）。
2. **调色层** `u2-art-shade`：线性压暗 + 顶部暖光，
   `linear-gradient(180deg, rgba(30,18,6,.04) 0%, rgba(30,18,6,.06) 40%, rgba(30,18,6,.42) 100%)`，
   叠一层 `radial-gradient(70% 50% at 50% 18%, rgba(255,255,255,.22), transparent 70%)`。
   目的：让白底人物和场景在任何素材下都能压到同一明度，且**文字所在的下沿更暗、卡面正文更跳**。
3. **人物层** `u2-art-person`：透明 WebP，`object-fit: contain`，`object-position: 50% 100%`，
   高度约占图区 **78%**，底部贴图区下沿 −4px（脚"踩"在图位边上），中心水平对齐。
   - 人物在图位下缘投一个椭圆软影：宽 140 / 高 16，`radial-gradient(closest-side, rgba(90,40,10,.35), transparent)`。
   - 人物永远压在场景之上、印章之下（`z-index`：场景 1 / 调色 2 / 人物 3 / 印章 5）。

### 5.3 无素材占位（必须与真图**版式完全一致**）

- 图框、圆角、内衬线、高度、下沿暗层**全部不变**。
- 场景层换成中性渐变 `linear-gradient(180deg,#f3e8c9,#e0cfa6)`；
- 人物层换成 **emoji 106~114px**（按图区高微调），**不加 `filter`**——WXSS 的 filter 支持不稳，
  融进暖调靠场景层与调色层做，emoji 本身保持原色；垂直位置与真图人物脚部一致（`bottom:-4px`）；
- 地面影保留；
- 判定方式：`ART_ON` 开关或单图 404 回落，**占位不塌版**（改前后截图逐像素检查版式）。

## 7. 小程序落地注意（红线）

1. **禁用**：`backdrop-filter`、`:has()`、CSS `mask` / `-webkit-mask`、SVG `filter` 做主体质感、
   大面积 `filter: blur`。质感只走「粗描边 + 双层硬投影 + 渐变 + 纹理」。
2. **HUD 液面**用 §3.2 的「外层定高 + overflow:hidden + 内层整图贴底」方案，
   **不许用** `clip-path`（WXSS 兼容差）或 SVG `<clipPath>`（WXML 不支持内联 SVG）。
3. **图标**：H5 用内联 SVG；小程序把每个图标导出为 **base64 data-URI** 的 `background-image`
   （4 个形状 × 3 层 = 12 个），或统一走 `canvas 2d` 绘制。形状几何与现在完全一致。
4. **分时图**：小程序用 `canvas type="2d"`（`devicePixelRatio` 缩放），角标用 view 叠加；
   不允许把整块行情区做成一张图（净值是文本，要能选中/读屏）。
5. **纹理**：纸张/斜纹一律 `repeating-linear-gradient`，没有硬件加速问题；
   若需要噪点，用 64×64 base64 PNG 平铺，`background-repeat: repeat`，**不用 SVG feTurbulence**。
6. 字号用 `rpx` 换算：375 设计稿下 **1px ≈ 2rpx**；但**不要**把 10px 以下文案改成 rpx 缩水，
   375 与 414 机型都要保住 10px 下限。
7. 无限动画（blink / breathe）同时最多 1 个；切后台要停（`onHide` 移除 class）。
