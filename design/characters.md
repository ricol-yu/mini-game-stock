## 0. 档位（2026-11-11 team-lead 改判，以本条为准）

| 档 | 角色 | 做什么 | 数据字段 | 新增卡 |
|---|---|---|---|---|
| **A 档 · 锁人设** | 老婆 `laopo`（32 张）、老妈 `laoma`（9 张） | 不加卡，只把**说话方式锁死**：老婆永远先问钱再问人，老妈永远先说身体再说钱。两条支线设定已备好但**本轮不进池** | **不加** `tier` / `stage` | 0（设定的 6 张留作下一批） |

| 普通高频角色（**归 A 档**，配额同 A 档：**≤5 次/局 · 间隔 ≥6 张 · 第 3 天前不登场**） | 同事小王 `tongshi_xiaowang`（3 张） | 保持 3 张，**不扩卡、不做弧线**。他是个好角色，但不需要"发展" | **不加** `tier` / `stage`，**不改数据** | 0 |
| **C 档 · 一次性** | 张阿姨 `zhangayi`、出租车司机 `taxi` | 一次性。杀伤力来自「突然冒出来说一句」，重复就废 | 无 | 0 |

**C 档的执行口径**：这两个 `wid` **单局每人 ≤1 次**，硬上限不是"尽量少出"。
判据：`if((S._onceCnt[wid]|0) >= 1) continue;`，出过一次就 `S._onceCnt[wid] = 1`（`reset()` 清空）。

**为什么 B 档给了「你的票」而不是小王**：小王那种「同事跟着买」的内容，抖音一抓一大把；
而「**我的股票开口跟我说话**」是这游戏独一份，别人抄不走——而且它**不需要新美术**（走空镜头）。
票的现有 4 张全是"卖 / 不卖"的动作卡，**没有一张是它自己开口**，这是最大的浪费，也是最好的支线素材。

**A 档和 B 档的区别不是"出现几次"，是"会不会变"**：
A 档是**同一个人在不同的处境里**（她始终是她）；B 档是**同一个东西在不同的时候**（从劝你持有，到沉默）。
所以 B 档要 `stage` 字段，A 档不要——A 档一旦有 stage 就变成连续剧了。

**合计 12 张的设定**（老婆 3 + 老妈 3 + 票 6），都不需要新图（走空镜头 / 现有场景）。
**进度**：票的 6 张 ✅ **已进池**（`data/cards.json` 现 171 张）；老婆「她的账本」3 张、老妈「她不懂股票」3 张 **⏸ 卡未进池**——设定表（§2.5 / §3.5）留着当**下一批的输入**，理由见下。

> **为什么这两段这轮不进池（2026-11-11 team-lead 决定）**：① 老婆 32 张、老妈 9 张已经是全场出现最多的两个人，再各加 3 张边际收益很低，而票只有 4 张、加 6 张是翻倍；② 一局平均只走 34 张卡（仿真 p50=32），3 张新卡一局最多出 1–2 张，**撑不起一条弧线**，玩家感觉不到「她在记账」；③ 卡池 171 张已经不薄，再加会稀释每一张的出现率——**脸熟是靠出现率堆的，不是靠总卡数**。
> 等这轮分享卡 + 票支线跑完、看完真实数据再议。

## 1. 名额预算

| 档 | 一局上限 | 最小间隔 | 最早登场 |
|---|---|---|---|
| A 档（普通卡：老婆 / 老妈 / **小王**） | **5 次** | **6 张卡** | 第 3 天 |
| B 档·你的票（支线卡，**不占** A 档 5 次配额） | **升段 2 次**（第 1 段登场不算升段）→ 本局最多走到第 3 段 | 段间 **≥8 张卡** | 第 1 段最早 **第 4 天** |
| C 档（张阿姨 / 司机） | **1 次** | — | — |

> **小王在 A 档，不在 C 档**（2026-11-11 team-lead 拍板）：他 3 张卡全是职场场景，「同事天天见」不违和；
> 限成 ≤1 次，另外两张就永远是抽不到的死卡。C 档只留给「靠突然出现才有杀伤力」的人。

> **「升段 2 次」怎么算**：`_pStage` 从 0 起，出第 1 段升到 1（不计入升段次数），之后 1→2、2→3 各算一次。
> 所以 60 天的长局能走完整条线（段 1 卡上写 `day>6`，之后每隔 ≥8 张：≈ 第 7 / 16 / 25 天），30 天的局自然停在第 1–2 段——**不需要额外判据，8 张间隔本身就把短局截断了**。
> `_pStage` 是**局内**状态，`reset()` 清空：每一世你都要重新把它说服一次。

机制实现（`recentWho()` / `C_ONCE` 白名单 / `piaoOK()` / `stage` 单调推进）见 `share-flow.md` §4.1–§4.2。

## 2. A 档 · 老婆 `laopo`（32 张，全场最多）

### 2.1 一句话人设

**她是「生活」本人。** 她不反对你炒股，她只是每天都在算：这个月的钱够不够。她的每一句话都是一个具体数字，或一个具体的时间。

### 2.2 语言指纹（写卡时照着对）

| 项 | 规则 |
|---|---|
| 句长 | **≤ 18 字**。她短句，不解释 |
| 句式 | 问句 > 陈述句。她提问时不带情绪词（「这个月够吗」而不是「你能不能省点」） |
| 数字 | **她的台词里数字比形容词多**（3,000 / 6,800 / 八万八 / 八点半）。她的世界是可数的 |
| **一定会说的句式** | **先问钱，再问人**：「这个月够吗？」→（你答完）→「那你今晚回来吃饭吗？」顺序不许反 |
| **绝不说** | 「股票」「行情」「仓位」「A 股」。她一律说「**你那个**」 |
| **绝不说** | 指责、说教、后悔（「你太贪心了」「早跟你说过」）——**一次都不许** |
| 称呼 | 婚前叫「女友」，婚后（`did:fam_hunli_01`）叫「老婆」。**只有这一处允许切换**，由事件驱动、不可逆 |
| 禁止 | 她的话里不许出现「韭菜」「割」这类梗——她不懂，也不会拿它开玩笑 |

### 2.3 口头禅：「这个月够吗？」

- 位置：**正文首句**，不许出现在选项里。
- 限额：**每局 ≤2 次**，两次间隔 **≥15 天**，第二次必须换处境（第二条必须带 `when`：`has:baby` / `debt>0` / `did:fam_ledger_02.l`）。
- 为什么是这句：她的整个存在就是一个现金流问题。这句话在「刚结婚」「有孩子」「欠着债」三种处境下说出来，是三种完全不同的压力——**同一句话，三次都成立**。

### 2.4 现有弧线（32 张映射到 5 段，写新卡前先读这张）

| 段 | 触发标志 | 代表卡 | 她的状态 |
|---|---|---|---|
| ① 女友 | `no:did:fam_queding_01` | `fam_yuehui_01` `fam_zhaohu_01` `fam_zhoumo_01` `fam_shengri_01` | 试探：你还愿不愿意来 |
| ② 摊牌 | `did:fam_queding_01` / `fam_liehen_01` / `fam_chenmo_01` | `fam_queding_01` `fam_liehen_01` `fam_chenmo_01` | 要一个答案；问「股票和我哪个重要」 |
| ③ 成家 | `did:fam_jiazhang_01` → `fam_caili_01` → `fam_hunli_01` | `fam_jiazhang_01` `fam_shitan_01` `fam_zanqian_01` `fam_caili_01` `fam_hunli_01` | 从「我们」变成「我们家」，价码开始出现 |
| ④ 婚后 | `did:fam_hunli_01` | `fam_mortgage_01` `fam_dinner_01` `fam_confess_01` `fam_pregnant_01` `fam_anniv_01` `fam_prenatal_01` `life_travel_01` | 生活压上来，她开始算账 |
| ⑤ 裂痕 | `mind<35` / `miss.lover>=7` / `did:fam_confess_02` | `fam_divorce_01` `fam_confess_02` `fam_lengzhan_01` | 不吵了，只是不再问 |

> 写新卡时**必须声明它在第几段**，`when` 里必须挂上进入该段的条件。挂在段外（例如婚后段写「周末去江边走走」）就是穿帮。

### 2.5 支线：「她的账本」（3 张 · **卡未进池**，下一批的输入）

**意图**：让你发现她一直在记账，而这件事你从来没问过。压力不是她查你，是"你连家里还剩多少都不知道"。

| # | id | 段 | when | 意图（正文只给处境，不给选项原文） | 两侧代价方向（每侧 ≥2 条数值、各付代价） |
|---|---|---|---|---|---|
| 1 | `fam_ledger_01` | ④ 婚后 | `did:fam_hunli_01; day>=35` | 她在餐桌上记账，你瞥见那一页比你清楚得多。她从没跟你提过 | 问 → `social+` / `mind−`（要承认自己没管过家）· 不问 → `mind+` / `risk+`（装没看见，继续自己玩） |
| 2 | `fam_ledger_02` | ④ 婚后 | `did:fam_ledger_01.l; day>=45` | 她提出「钱分开管」。不是吵架的语气，是通知 | 同意 → `cash−`（交出一半现金）+ `social+` · 拒绝 → `social−` / `mind−` + `risk+`（钱全在你手上，你更敢动） |
| 3 | `fam_ledger_03` | ④ 婚后 | `did:fam_ledger_02.l; day>=55` \| `did:fam_ledger_02.r; day>=55` | 她把记账本推到你面前，上面有一行写「他的股票」 | 看 → `mind−6` 左右 + `social+` · 不看 → `mind+` / `social−` |

示范台词（锁语气，不是终稿）：
> 她在餐桌上记着什么。你把手机扣过来的时候，她已经写完了。
> 「这个月够吗？」——她问的是这个月，不是你那笔。

### 2.6 禁止清单

- ❌ 让她讲行情、劝你止损、说「你该卖了」——**她不懂，也不该懂**。
- ❌ 让她说教。
- ❌ 在同一局里既出现「婚事」段又出现「裂痕」段（那需要 5 张以上，超名额，时间线也会崩）。

## 3. A 档 · 老妈 `laoma`（9 张）

### 3.1 一句话人设

**她不懂股票，但她懂你。** 她只会用「吃了没」「别熬夜」「钱够不够」三句话，关心一个正在把命押在一根线上的人。

### 3.2 语言指纹

| 项 | 规则 |
|---|---|
| 句长 | **≤ 15 字**，比老婆更短。她的台词是碎片 |
| 句式 | 全是问句和要求，没有陈述句。她不分析 |
| **一定会说的句式** | **先说身体，再说钱**：「最近睡得好吗？」→「钱够不够？」重量永远在身体那边 |
| 唯一允许的「行情词汇」 | 「**涨了没**」——她只知道这两个字。**绝不许**出现「跌停」「止盈」「仓位」「割肉」 |
| 动作 | 她**寄东西 / 塞钱 / 打电话**。关心永远是物化的（腌笋、报纸包的钱、后备箱） |
| **绝不说** | 抱怨、要钱、说自己不舒服的细节（她的病永远由第三个人——体检单、邻居——转述） |
| 称呼 | 永远「老妈」。**不许写「母亲」**（太书面） |

### 3.3 口头禅：「别熬夜。」

- **每局 ≤2 次**，间隔 ≥15 天，第二次必须换处境（`has:fired` / `day>=60` / `did:fam_momhealth_01.l`）。
- 为什么是这句：她的关心点不在钱上，在身体上——而身体是这个游戏里**第一条会爆的命**（`亮红灯` 结局）。她永远比你早发现。

### 3.4 现有弧线（9 张，已有生死线）

| 段 | 触发 | 卡 | 她的状态 |
|---|---|---|---|
| ① 日常 | `no:has:momgone` | `fam_momcall_01` `life_parents_01` `fam_momhealth_01` | 打电话、手机卡、血压高 |
| ② 钱 | `no:has:momgone` | `fam_eldermoney_01` `fam_hospital_01` | 把养老钱给你 / 你爸住院要垫钱 |
| ③ 疏远 | `did:fam_momcall_01.l` | `fam_momcall_02` `fam_hospital_02` | 邻居说她在菜市场叹气 / 你没接那个电话 |
| ④ 终点 | `miss.fam>=3` + `day` 阶梯 | `fam_momgone_01` | 电话响到自动挂断 |

> 第④段是全游戏最重的一处，**别在它前面加任何「和解」型支线**——和解会让它失去重量。

### 3.5 支线：「她不懂股票」（3 张 · **卡未进池**，下一批的输入）

**意图**：她试着理解你在干什么，方式是错的、笨的，但是认真的。
这条线里她说的每句话**在机制上都是错的、在情绪上都是对的**——这是它全部的力量。

| # | id | 段 | when | 意图 | 两侧代价方向 |
|---|---|---|---|---|---|
| 1 | `fam_momask_01` | ① 日常 | `no:has:momgone; day>=20` | 她问「你那个涨了没」。她其实只知道涨/跌两个词，问完就转到「吃饭」 | 认真答 → `mind+5` 左右 + `energy−`（要解释很久）· 敷衍 → `mind−` + `social+2`（省了时间，她记住了你的敷衍） |
| 2 | `fam_momgift_01` | ② 钱 | `no:has:momgone; cash<3000` | 她塞给你一叠用报纸包的钱，说「拿着，别告诉你爸」 | 收 → `cash+` / `mind−`（60 岁的人的钱）· 不收 → `mind+` / `social−`（她会觉得你嫌少，几天不打电话） |
| 3 | `fam_momquiet_01` | ③ 疏远 | `did:fam_momgift_01.l; day>=40` | 她说「妈不缺钱，你回来吃顿饭就行」——而你这周在等一个开盘 | 回去 → `energy−` / `social+` / `mind+` + `risk+`（没盯盘）· 不回 → `mind−` / `social−` + `cash+`（省下路费和时间） |

示范台词：
> 「别熬夜。」她说完就把电话挂了，像这句话不需要回答。

### 3.6 禁止清单

- ❌ 让她给出正确的投资建议（合规 + 人设双杀）。
- ❌ 让她主动要钱、抱怨孤独（那是「可怜」，不是「克制」）。
- ❌ 让她和老婆在同一张卡里同时说话——卡面只有一个图位。

## 4. B 档 · 你的票 `nidepiao`（4 张 → 10 张，全场唯一一条支线）

> 3 段（**说话 → 评价你 → 沉默**）· 本局最多升段 2 次 · 新增 6 张 ✅ **已进池** · 前端频次判据见 `share-flow.md` §4.2

### 4.1 一句话人设

**它没有名字，也没有脸。** 它是你账户里那串数字忽然开始说话——不是「股票精灵」，是**行情本身长出了声音**。
它只在你耳边说「还能再涨一点」：涨的时候是诱惑，跌的时候是挽留。它说的每句话都指向明天，从不回顾。
**它从不提「后果」，因为对它来说后果不存在。**

### 4.2 三条不可违反（比任何台词技巧都重要）

| # | 铁律 | 落地判据 |
|---|---|---|
| ① | **台词只用第一人称「我」** | 它**开口时**只说「我」，不说「这只票」「这只股」。旁白仍可用「它」（那是你脑子里的第三人称），但**引号里必须是「我」**。全场只有它用第一人称——这是它唯一的指纹 |
| ② | **只谈价格和明天，从不谈后果** | 禁用：具体金额、生活、家人、亏、套、割、风险、止损、「以后怎么办」。可用：我 / 涨 / 跌 / 明天 / 再等等 / 还差一点 |
| ③ | **不许可爱化，不许有脸** | 不撒娇、不委屈、不说「别卖我」；`avatar` 只能是行情符号 **📈 / 📉 / 🔴**，一个表情类 emoji 都不许有 |

> ③ 的现状：现有 4 张实测已是 `📈 📉 🔴`（`dec_takeprofit_01` 📈 · `dec_stoploss_01` 📉 · `dec_limitup_01` 🔴 · `mkt_paperwin_01` 📈），**零人脸、零表情**——已合规。
> 扩的 6 张继续只用这三个符号，**不许新增第四个**：多一个符号就等于给它添了一层"性格"，而它不是角色。
> 「不许可爱化」和「不许有脸」是同一条——**它一旦有了表情，玩家就会心疼它，而它不该被心疼。**

### 4.3 语言指纹（这条线最要紧的部分）

| 项 | 规则 |
|---|---|
| 人称 | **第一人称「我」**。它是全场唯一用「我」的角色（其他角色都在说「你」） |
| 句长 | **≤ 12 字**。全场最短。它的话像耳边的念头，不像对话 |
| 内容 | 只谈**价格、可能性、明天**。**绝不谈**钱、生活、家人、后果 |
| 时态 | 永远指向未来（「明天」「还会」「再等等」）。**它从不回顾** |
| **绝不说** | 「对不起」「我错了」「你该卖了」。也**绝不说**「风险」这个词——它不承认风险存在 |
| 谈你的方式 | **只在第 2 段开始说「你」**：「你拿得住。」「你上回就卖了。」「你算过还差多少吗。」——它**只描述你，不建议你**。它一旦开始建议，就变成了分析师，而分析师是会被骂的 |
| 语域 | **不许可爱化**（不许「不要卖我嘛」）——它不是宠物，是行情 |
| 唯一允许的犹豫 | 数字。它可以说「再涨两点」「还能一个板」，但**不许说具体价位**（它不知道该值多少） |

### 4.4 弧线：3 段（说话 → 评价你 → 沉默）

```
  ①它开口 ─────→ ②它开始评价你 ─────→ ③它不说话了
  （涨 / 封板）      （泡沫 / 横盘 / 已经亏了）    （停牌 / 崩盘 / 归零）
```

| 段 | stage | 本段行情处境（`when` 用这些真标志） | 核心台词方向 | 这一段在说什么 |
|---|---|---|---|---|
| ① 它开口 | 1 | `equity>cost` / `has:bull` | 「我还能再涨一点。」 | 诱惑：它给你的从来不是判断，是**把决定往后推一天**的理由 |
| ② 它评价你 | 2 | `has:bubble` / `has:bear` / `equity<cost` | 从讲价格转向讲**你**：「你拿得住。」「你上回就卖了。」「你算过还差多少吗。」 | 它开始**替你算账、替你找理由**——撒的是你想听的那个谎，而且开始给你打分 |
| ③ 它沉默 | 3 | `has:halt` / `has:crisis` / `equity<=0` | **没有台词。** 正文只写「屏幕上什么都没有」 | 沉默：这才是终点。它不恨你，它只是不在了 |

> **段 ② 从"讲价格"换成"讲你"，是它从诱惑变成刺痛的那一下**：它比任何人都清楚你上次是在哪儿卖的。
> 段 ③ 的卡面**必须一句它的话都没有**（连引号都不许出现）——这是整条线的落点，写成"你听见了沉默"就全废了。
> **它从段 ② 起就不再报一个新价格**：一个不再报价的东西，比一个报价很低的东西更让人慌。

### 4.5 口头禅：「我还能再涨一点。」（**可选**，当前 6 张未使用）

- **现状**：已落库的 6 张里**没有**这句——它的语气靠「第一人称 + 把你的名字换成『我』」立住，不靠复读。**这是可以的**，别为了"有口头禅"硬塞。
- 如果以后要用：**每局 ≤2 次**，两次间隔 **≥15 天**，第二次必须换处境（`has:bubble` / `has:bear` / `equity>cost`），且**只许落在 stage 1–2**——走到第 3 段（沉默）之后永不再出现。
- 为什么当初选这句：它是这个游戏的核心谎言，在**多个处境下都成立**——涨的时候是贪，横盘是安慰，泡沫里是遗言。

### 4.6 卡量（6 张已进池：`piao_voice_01`–`04` + `piao_silent_01`–`02`）

现有的 4 张（`dec_takeprofit_01` `dec_stoploss_01` `dec_limitup_01` `mkt_paperwin_01`）全是"卖 / 不卖"的**动作卡**，
**没有一张是它自己开口说话**——这是要扩线的全部原因。已落地的 6 张长这样：

| 段 | stage | 张数 | 构成 |
|---|---|---|---|
| ① 它开口 | 1 | **2 张** | `piao_voice_01` 📈「你盯着我看了很久了。」／ `piao_voice_02` 📉「你今天，会卖了我吗？」——**涨/跌两个互斥变体**，抽到哪张看本局行情 |
| ② 它评价你 | 2 | **2 张** | `piao_voice_03` 📈「你还差多少？」／ `piao_voice_04` 📉「你昨天说的话，今天还算吗？」——**算账变体**，同上 |
| ③ 它沉默 | 3 | **2 张** | `piao_silent_01` 🔴（`has:halt`「它不说话了。停牌公告还是没有来。」）／ `piao_silent_02` 🔴（`has:crisis`「它不说话了。你也没再问。」）——**正文里一句台词都没有** |

- 合计 **6 张**；加上现有 4 张，`nidepiao` 全场 **10 张**。一局最多见 3 张（每段 1 张）。
- **同段两张是「互斥变体」而不是「往返」**：`when` 相同、只有行情符号不同，所以同一局只可能见到其中一张（另一张因 `stage` 已推进而永久失效）。**不要指望看到「它说一句、你回一句」两张连着出**——那需要 2 倍的卡量，不值。
- **不加 `did:`**：段位顺序由 `stage` 闸门保证（`share-flow.md` §4.2），`did:` 只在真的需要「你回了它一句」时才补。
- **现有的 4 张动作卡不加 `tier` / `stage`**：它们是普通决策卡，不是支线。支线只由这 6 张构成。

### 4.7 数据字段（前端照这个落，字段名以 `data/cards.json` 现有卡为准）

```js
{ id:"piao_voice_01", who:"你的票", whoId:"nidepiao", avatar:"📈", tag:"决策",
  tier:"B", stage:1,                        // ← B 档必须成对出现，缺一个校验器就红
  when:"day>6; equity>500",                 // 段 1：先买过、拿过几天
  text:"…",                                 // 段 1/2 是它的话；段 3 里不许出现「我」
  left:{…}, right:{…} }
```
- `stage` 取值只有 `1 / 2 / 3`，每段 2 张（同一段的两张 `when` 相同、只有 `avatar` 涨/跌不同）。
- `tier:"B"` 的卡**不累加** `S._whoCnt`（不占 A 档 5 次配额），只推进 `S._pStage`。
- `avatar` 只许 `📈` / `📉` / `🔴` 三者（§4.2 铁律 ③）。
- 校验器加三条：`tier:"B"` 必须同时有 `stage`；`stage` ∈ {1,2,3}；`stage===3` 的卡 `text` 里**不许出现「我」**。
- `did:` 的用法**不对称**（故意的）：**段 1/2 不绑前置**（段 2 台词单独成立，绑了会永远出不来）；**段 3 必须绑段 2**（`did:piao_voice_03.l|.r|did:piao_voice_04.l|.r` 长 OR），防「没开过口就突然沉默」。顺序由 `stage` 闸门兜底，`did:` 是第二道。

### 4.8 禁止清单

- ❌ 让**段 2/3 的卡绕开 `stage` 闸门**被抽到（跳段 = 它莫名跳过了中间那一步）。闸门判据见 `share-flow.md` §4.2。
- ❌ 让它说「风险」「止损」「仓位」——它不承认这些东西。
- ❌ 让它表现出情绪（害怕、后悔、撒娇）。
- ❌ **给 `avatar` 添第四个符号**（现在只有 📈 / 📉 / 🔴，够了）。
- ❌ 让它出现在**别人的卡**里说话（它是「你的」票，只跟你说话）。
- ❌ 段 ③ 之后让它复活（沉默是终点，不是中场休息）。

## 5. 交叉约束

| 约束 | 理由 |
|---|---|
| 同一张卡只能有**一个** `whoId` | 卡面只有一个图位，两个人说话会让图位指错人 |
| 老婆与老妈**不许连续出现** | 两个家人连着来 = 「今天全是家里事」，会让人以为这游戏是家庭伦理剧 |
| `nidepiao` 与任何人都可以同局出现 | 它是行情，不是人——它和"今天谁来找你"没有关系 |
| 老婆 / 老妈**不早于第 3 天**登场 | 第 1–2 天是教程与世界观 |
| `nidepiao` 第 1 段**不早于第 4 天** | 你得先真的买过、拿过几天，「它开口」才有对象（比家人晚一天） |
| 张阿姨 / 司机**单局每人 ≤1 次** | 一次性角色，第二次就变成邻居（`S._onceCnt`） |
| 任何人在**结局判定的那一张**卡之后不许出现 | `check()` 一旦命中就结算，出现即视为 bug |

## 6. 给出立绘的人

| 项 | 规则 |
|---|---|
| 构图 | **一个 `whoId` = 一张固定构图**。不许换角度、换装、换景别。差异只走 `emo` 差分（同尺寸整图换脸） |

| `laoma` 表情 | 平静 / 笑 / 疲惫 |

| 画布 | 640×720，头顶 16%（`art-asset-spec` v3） |
| 占位 emoji | 处境符号可以随处境变，**人脸只能一个**（`share-flow.md` §8.1.1） |

## 7. 给做分享卡的人

- 五套模板里 **T5 温情版**有 1040 高的满幅插画位。口径（以 `share-card-spec.md` §4.5 为准）：
  **T5 = 场景层 + 压暗 + 文字，不叠人物层，也不为分享卡单独出人像**。素材只用卡面 640×720 的 `scene_*.webp`（cover，scale `max(1080/640,1040/720)=1.6875`，顶部对齐，溢出由压暗层与绒布盖住）。
  → **不许为分享卡新出构图**：插画区是满幅 640 高，卡面图区是 309×350，比例完全不同，塞进来就要重新摆 pose，等于第二套美术；而且一旦「海报上的脸」和「游戏里的脸」对不上，玩家会认为是两个人。
  → 场景图缺失时走 §4.5.3 降级（中性渐变铺满 + 居中 180px emoji 物件），**文字坐标一字不改**。
  → 关系断裂类结局（没有人 / 离婚 / 不认识 / 错过的人）用**空景变体**：同一版式，只把插画换成「没有人」的空镜头（半张椅子 / 一只拖鞋 / 关掉的电视）——和 `nidepiao` 走同一条渲染路子。
- 分享卡上**不出现角色名字**，只有结局名 + emoji + 引言。
- **分享卡的页脚是固定的**（`结局 No.xx · 由《韭菜之王》生成 · 可在设置里关闭`），**不受支线进度影响**——图要成套，`No.xx` 的连续感不能被抖（2026-11-11 与 visual-architect 对齐后改判）。
  支线进度改放 **App 内结局页**：`S._pStage >= 2` 时在 `.why` 下方多一行 20px 小字，从 `warm` 句池抽，**不进图**。详见 `share-flow.md` §4.5。
- `nidepiao` 的结局绝大多数走 T3 嘴硬 / T4 清算，都是纯排版，**不需要插画**——正好和它"没有脸"一致。
