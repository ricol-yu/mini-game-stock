- **12/13 个结局被触发**。「一次都没买」在随机玩家模型下出现 0 次——它要求整局

  仿真永远测不到它，属正常，不要当成 bug 修。
- 「自由」结局 2.5%：作为游戏最高奖赏，触达率偏低，N2 扩容时可以考虑给它
  多铺几条路（当前只有一条 80,000 净值线）。
- 心态归零是最大死因（34.2%）——卡池对心态的挤压可能偏重，N2 写新卡时留意。

## L1 决策感改造后的基线（2026-10-21，97 张）

用户玩后反馈「只有加没有减，没有王权那种牵制」，据此做了全池改造：
52 张卡的选项重写 + 3 张剧透卡改正文 + 2 个 id 更名。规则写进 `AGENTS.md` 和校验器第 9 类检查。

### 单卡质量（`check-dominance.js`）

| 指标 | 改造前 | 改造后 |
|---|---|---|
| 伪选择（某一侧全面占优） | 22.8% | **0.0%** |
| 存在「全赚不赔」选项的卡 | 32.0% | **0.0%** |
| 只触及 1–2 条数值的卡 | 41.2% | **6.2%** |
| 正文剧透选项 | 8 张 | **0 张** |

> 口径提醒：可自动判定的卡从 57 张降到 52 张（多了 5 张因含 `sell/buy` 转入「需人工看」），
> 0% 是在更小的分母上取得的，但仍是最干净的一次。

### 玩法结构（`check-policy.js policy --runs 3000`）

| 玩法 | 改造前 | 改造后 |
|---|---|---|
| 随机乱滑 | x1.00（20.9%） | x1.00（14.9%） |
| 永远左滑（什么都拒绝） | x0.55 | **x0.03** |
| 永远右滑（什么都认了） | x0.18 | x0.24 |
| 老好人（只看心态+社会） | x0.33 | **x0.10** |
| 会玩（只看最短板，线性权重） | x0.70 | x0.60 |
| 会玩·maximin（先保住最短板） | — | **x4.50** |

**读法**：两条「躺赢路线」被打掉了——什么都拒绝从次优（0.55x）变成自杀（0.03x），
老好人从 0.33x 掉到 0.10x。maximin 4.50x 说明「看代价、保短板」确实有回报。
注意所有策略都是**看得到数值的机器人**，它们的绝对通关率不能当人类难度看，只有倍率有意义。

### 结局分布（`simulate.js --runs 3000`，seed 20261020，同仿真器 A/B）

| 结局 | 改造前 | 改造后 |
|---|---|---|
| 活满 60 天 | 17.5% | 17.4% |
| 不动了（心态归零） | 25.5% | 24.7% |
| 穿仓 | 16.4% | 17.3% |
| 一无所有 | 14.7% | 14.9% |
| **没有人** | 6.9% | **11.7%** |
| 泡沫之后 | 9.5% | 9.1% |

**结论**：整体难度没变（17.5%→17.4%），但死法结构变了——**「没有人」几乎翻倍**。
这是有意的：拒绝入局不再免费。社交现在是第四大死因，符合「人情社会」的主题。

### 还没解决的

`check-policy.js scan` 显示 **34 张卡（35%）怎么滑都不影响胜负**（改造前也是 34%）。
L1 只能让「选项」有分量，不能让「路线」有分量——那需要 N3 关联卡（延迟清算）与
「攒现金反奖励」。批 2 之前建议先定这两件。
