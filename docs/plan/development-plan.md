## N2 · 卡池扩容 63 → 220 `[ ]`

分 4 批，每批固定动作：**写卡 → 校验 → 仿真对比基线 → 提交**。任何指标恶化超过阈值（结局触发率变化 > 2 个百分点）就停下讨论。

- [ ] 批 1（+34）：家庭 / 职场 / 自己 —— 角色复用优先，把「只出场 1 次」的 39 个角色先救活 10 个
- [ ] 批 2（+34）：市场 / 风险
- [ ] 批 3（+41）：收入 / 决策 / 意外 / 人情 → **到 180 张时验一次单局重复率（目标 < 40%）**
- [ ] 批 4（+48）：补到 220，重心放常驻角色（20 人 × 6–10 张）

**写作约束**（写每张卡时对着看）：卡面 ≤31 字；选项 ≤11 字；只陈述后果不说教；`spend` 与 `risk` 是负向；每个 tag 里意外/收入/决策三类不许为 0。

**节点验收**：单局重复率 < 25%；支配选项 < 5%；无从没出现过的卡。
