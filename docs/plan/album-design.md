# 结局图鉴设计方案（草案 v1 · 待拍板）

> 2026-11-10 · Mac 端拟。布局骨架已随主菜单上线（`fa09d12`）：主菜单 → 📖结局图鉴 → 4×3 网格。
> 本文档只管「图鉴该长什么样、怎么解锁、怎么驱动重玩」，你敲定后实施。

## 1. 定位

图鉴不是战绩页，是**下一局的理由**。它要回答玩家三个问题：

1. 我这辈子都活成过什么样？（已解锁 → 白描 + 记录）
2. 还有哪几种活法我没见过？（未解锁 → 悬念 + 方向感）
3. 那种活法怎么才能见到？（达成路径 → 复现的教学价值）

配合次数制：**「还差 5 个结局」是最自然的「再看一支广告」的理由。**

## 2. 网格格子的两态

**已解锁**（现版已有，本方案加细）：

```
┌──────────┐
│    🪙    │   emoji（彩色）
│   自由   │   结局名
│ 第1次 · 11-10 │   首次达成日期
│ 最长 47 天 · ¥82,310 │   最佳记录（多次达成取最优）
│     ×3   │   达成次数（右上角小角标）
└──────────┘
```

**未解锁**——待拍板点 A，三选一：

| 方案 | 显示 | 效果 |
|---|---|---|
| A1 全遮（现版） | ❓ + 「？？？」 | 悬念最大，但玩家没有方向感，可能永远差那几个 |
| A2 给模糊线索（**推荐**） | 剪影 emoji（灰阶）+ 「？？？」+ 一句方向话 | 悬念保留，探索有靶子 |
| A3 给完整条件 | ❓ + 条件原文 | 变成就清单，收集感最弱，不推荐 |

A2 的方向话示例（只给「与什么共舞」，不给阈值）：

| 结局 | 方向话 |
|---|---|
| 自由 | 账面上够你安静很久的那个数字，是多少？ |
| 上岸 | 全场唯一一个「不玩了就算赢」的结局——试试亲手按下停止键 |
| 两个人 | 钱没大赚，但照片挂在客厅 |
| 熬成精 | 五个月了，你还站着 |
| 一次都没动 | 除了底仓，你再没碰过它 |
| 泡沫之后 | 它涨的时候你也觉得不真实 |
| 最后一把 | 那一单，比平时大得多 |
| 冬天还没过完 | 你没有做错什么，只是正好站在了那儿 |
| 不动了 / 没有人 / 穿仓 / 爆了 | （各自 quote 里抽半句） |

## 3. 结局详情页（点格子展开）

- **已解锁**：复用结局面板（endcard）内容重放：emoji / 标题 / 副题 / 白描 / why + 一行
  「怎么达成」（解锁时写入记录的条件摘要，如「风险打满 100」）。
- **未解锁**：弹一句 A2 方向话，不泄题。
- 实现成本：纯展示层复用，无新逻辑。

## 4. 分区方式——待拍板点 D

| 方案 | 说明 |
|---|---|
| D1 平铺 4×3（现版，**推荐**） | 一屏看完，「收集缺口」一目了然；12 格体量不大，分区反而稀释 |
| D2 活法/死法两组 | 赢面（自由/上岸/两个人/熬成精/一次都没动）vs 输面，组头加小标题 |

12 个结局体量下推荐 D1；将来结局扩到 20+ 再切 D2。

## 5. 进度激励（轻量版）

- 主菜单图鉴入口的 `x/12` 保留；**集齐里程碑给称号**，显示在主菜单战绩 chip 后缀：
  - ≥1：韭菜学徒 · ≥4：Flømme 老手 · ≥8：老韭菜 · 全集齐：**韭菜之王**
- 全集齐那天主菜单弹一次庆祝印章（复用动效层 stamp）。
- 称号只做主菜单文案，不进局内——局内的克制白描风格不许被成就系统污染。

## 6. 数据结构（META 扩展，向后兼容）

```js
META.unlocked[name] = { em, days, net,          // 现版已有
                        times: 1,               // 达成次数（重复达成 +1，记录取最优）
                        first: "2026-11-10",    // 首次达成日期
                        how: "风险打满 100/100" } // 条件摘要（详情页用）
```

上线时整包挪到云端（openid 主键），字段形状不变。

## 7. 不进这一版的（明确砍掉）

- 结局限时活动 / 图鉴分享海报（小程序分享卡二期）
- 结局重放局内回放（成本高，价值低——why 文案已承担复盘）
- 抽象进度条（`x/12` 数字本身已够）
