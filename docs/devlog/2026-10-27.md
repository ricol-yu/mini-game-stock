# 2026-10-27

## 第九轮（Windows 端）：欠账清算——每条线都要有牙齿

> 用户拍板：「次数不需要显性告诉玩家，只要累计对父母/宠物/孩子/伴侣亏欠的次数达到要求，
> 就触发欠账清算卡；清算卡选两边都一样，目的是告诉玩家已经成了既定事实。」

### 机制：S.miss 欠账计数（对玩家完全隐藏）

- 卡牌选项可标 `miss:'fam'|'child'|'pet'|'lover'`（data/cards.json 选项级字段），
  `resolve()` 里 `S.miss[线]++`——没有 HUD、没有进度条、没有提示。
- when 新增两种写法：`miss.fam>=3`（计数比较）和 `no:has:momgone`（反向状态，三处解析器同步：
  原型 oneCond / sim engine parseCond / validate parseWhen）。
- 打标规则：默认「社交更低的一侧 = 亏欠侧」（同社交比心态），`tools/add-miss-cards.js` 里的
  NO_MARK 是人工否掉的两边都是好意/都在谈钱的卡。**左右不对称是真实存在的**
  （有的卡左=陪、有的卡右=陪），不能按左右硬套——这点抽查前想当然了。

### 四张清算卡（urgent + cap 1 + fact，两边效果完全相同）

| 卡 | 触发（阈值随天数抬高，长局不是罪） | 效果 |
|---|---|---|
| 📵 妈的电话不会再来了 | miss.fam 3/4/5（45/65/95 天起） | 心态−14 社会−13，momgone 关掉爸妈 8 张卡 |
| 🎓 毕业照里没有你 | miss.child 3/4/5 | 心态−11 社会−11，childgone 关掉孩子线 |
| 🐈 猫被送去你妈家 | miss.pet 2/3/4 | 心态−8 社会−4，petgone 关掉宠物线 |
| 🚪 她搬走了 | miss.lover 4/5/6（仅婚前） | 心态−10 社会−12，lovergone 关掉伴侣线 |

- 离婚卡新增欠账出口：`miss.lover>=7; did:fam_hunli_01; day>=70`（已婚的人走既有离婚卡）。
- **阈值为什么要随天数抬高**：绝对阈值下 maximin（活 100 天）40%+ 被清算——
  活得久卡片就多，计数自然涨。改成三档后 maximin 回落到 22%，且对照实验成立：
  老好人策略（只看心态社会）触发率 **0.0%**，只盯盘策略（只算钱）fam 100% 中招——
  机制只在真的亏欠时咬人。
- **线关闭不走 tag 门闩一处**：爸妈 8 张卡用 when 守卫（家人分类里混着丈母娘，
  她属于婚姻线不能连坐），孩子/宠物/伴侣按 tag 整条关（LINE_GONE，挡在
  bagShuffle/bagFind/bagFindChain/urgentFind 四处）。

### fact 卡的新规则（validate + check-dominance）

- 两边效果必须逐字段完全相等（否则报错）——既定事实不是选择；
- 必须 urgent + cap 1 + 带 when；
- 伪选择检查豁免（本来两边就一样），渲染成 `.card.fact`：正文下多一行居中灰字
  「已经这样了」，底部两个选项不再标红/绿——这不是选择题，是账单。

### 实测（700–3000 局）

- maximin 通关 79.8%、p50 96（改前 79.7% / 94，基本不动）；技巧回报 x11.40（红线 ≥2）。
- 随机乱滑结局分布逐位级稳定（p50 34 天、上岸 9.7%）。
- 伪选择 2.1%；smoke-ui 22 项全绿（新增 6 项断言：计数加减、阈值门、线关闭、
  婚前限定、fact 渲染、HUD 不露计数）。

### 工具

- `tools/add-miss-cards.js`：一次性打标 + 新增清算卡脚本（保留，注释里写明打标规则）。
- `tools/diag-miss.js`：欠账体检——各线计数分布 / 清算卡触发率 / 结婚率（婚礼后活着口径）/ 寿命，
  内置「老好人 / 只盯盘」两个对照策略专门验证机制 discrimination。

## 第二轮（10-27 晚）：「卖股票抵」整个拆掉——系统不再替玩家卖资产

> 「感觉钱不够卖股票抵这个逻辑很奇怪，比如阿姨推荐我买一只股，我现金不够，卖了股票再买股票。」

### 用户碰到的那张卡

`soc_insider_01`「张阿姨拉住你：有个内部渠道，稳得很」右侧「投五千试试」——
效果写的是 **spend 5,000**（钱直接消失），不是 buy。于是现金不够时：
系统卖掉你手里的股票凑出 5,000 → 交给张阿姨 → 钱没了、持仓没多。
从玩家视角就是「卖了股票去买股票，结果股票还没买到」。

### 但根子上的问题是机制，不是这张卡

旧 `spend()`：现金不够 → **自动砍仓抵账**（心态 −5）→ 还不够才记负债。
股票被当成了自动提款机，卖资产这个不可逆决定由系统代劳。

**新规矩：系统永远不替玩家买卖股票。**

| 操作 | 现金不够时 | 提示 |
|---|---|---|
| buy（买入） | 按现金实买，绝不碰持仓 | 选前「现金只够买 ¥1,200」/ 选后「只买到 ¥1,200，还剩 ¥1,800 没买上」 |
| spend（支出） | 现金清零，差额全额记负债 | 选前「差 ¥3,800，会欠着」/ 选后「现金不够，欠下 ¥3,800（每月要还）」 |
| sell（卖出） | —— | 只能玩家自己选（卡片上的卖出/减仓选项） |

### 配套

- `soc_insider_01` 文案点破歧义：「钱得先给」；`soc_scam_01`「投 6,500」→「给 6,500」
- validate 新规则：**同一侧禁止 buy 与 spend/repay 混写**（钱到底变股票还是花掉，玩家分不清）
- smoke-ui 重写 3 条断言（共 25 项）：不砍仓 · 买入差额记账 · 两种预警分开

### 实测（2000 局）

- **认真玩几乎无感**：maximin 通关 79.8% → 81.1%，第 37 天现金 p50 10,965 → 10,624，技巧回报 x11.19
- **乱玩的人死得更"对"**：穿仓结局 6.95% → 13.95%——乱花钱欠一屁股债，最后欠的比拥有的多，
  这正是这套新逻辑该教的事；「不动了」（攒不出钱闷死）62% → 55.6%
- 老好人策略清算触发率仍 0.0%，欠账机制无回归

## 第三轮（10-27 晚）：还款节点与老赖——欠债要有明确的账期

> 「欠的债也会设置一个定期的还款节点，如果还不上就会变成老赖，会有一个 debuff」

### 设计

**还款节点 = 每月两次**：5 号（发薪日，跟房租一起扣）+ 20 号（月中，没有工资撑腰）。
每次还欠款的 12%（最低 500），一个月合计 24%。

为什么必须两次：仿真实测只挂 5 号时触发率 **0%**——一局中位寿命三十几天只能赶上一次
还款日，玩家永远见不到「还不上」的下场。20 号那天没有工资，前面半个月的日用
已经把现金磨薄了，这才是真的掏不出来的时候。

**逾期记账（S.arrears）**：
- 还满当期应还 → 记录 −1（慢慢洗白，不是一键归零）
- 还了六成以上 → 记 1 笔逾期
- 六成都不到 → 记 2 笔（这是真违约）
- **攒到 3 笔 → 上失信名单**

**老赖（st.laolai，永久状态，还清债才解除）**：
- 心态每天 −1.2、社会每天 −0.2（催收电话、睡不好）
- 发薪日工资被法院强制划走 25% 直接还债（`LAOLAI_GARNISH`）
- 只能借到一半的钱（`borrow()` 减半，toast 说清「失信名单上借不到全款」）
- 两张专属卡：📞 催收电话打到家里 · 🚄 限高出差坐不了高铁（只挂 `has:laolai`）

**过程必须可见**：HUD 常驻「⚠️ 逾期 2/3」红标（攒够了要出事，玩家得能预见）；
还款胶囊有债时变红、显示「房租+月供」合计数；老赖状态亮红标「老赖」。
（对比：陪伴线的欠账计数是藏着的——因为那是"感情的账"；钱是明账，必须亮出来。）

### 调参过程（写成数据，防止以后再拍脑袋）

| 试过的参数 | maximin 成老赖率 | 结论 |
|---|---|---|
| 只挂 5 号 / 12% | 0.0% | 赶不上还款日，机制形同虚设 |
| 两次 / 9% | 0.3% | 还款太轻松，还是见不到 |
| 两次 / 15% + 还大半也记 1 笔 | **36.1%** | 太狠，认真玩家三分之一上名单 |
| 两次 / 12% + 还大半不记，<六成记 2 笔 | **3.7%** | ✅ 采用：极端情况才上名单 |

### 实测（2000 局）

- 结局分布与改前基本持平：上岸 9.35%（改前 9.8%）、穿仓 12.5%（改前 13.75%）
- maximin 通关 80.8%、技巧回报 x12.53（红线 ≥2.0）
- smoke-ui +8 断言共 31 项全绿（两次还款日、逾期分档、划扣、借钱减半、自动解除、专属卡条件）
