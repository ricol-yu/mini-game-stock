# 2026-10-25 · 借钱机制重做：钱进现金、负债上进度条

## 用户反馈
「借贷或者父母给我钱，总金钱数值应该要加上去，通过进度条显示我的负债或借款。」

## 问题（旧行为）
- `borrow()` 把借来的钱**直接塞进持仓**：现金一格不动、金钱数字没反应，玩家完全感知不到「钱到账了」
- 负债条是叠在金钱条上的**灰白斜纹**，和背景几乎分不清
- 连带 bug：彩礼卡「借 60000 + 花 28000」，borrow 进持仓后现金为 0，spend 触发**强制砍仓付彩礼**（心态 −5），体验错乱

## 改动（全部在 prototype.html，引擎直接加载原型脚本所以自动同步）
1. `borrow()`：`debt+=x; cash+=x` —— 借来的钱先进现金、欠账记进负债，花不花买不买玩家自己定（净值仍为 0，负债+风险代价不变）
2. `apply()` 顺序：`cash → borrow → buy → sell → spend → repay`（borrow 提前，同卡 borrow+spend/buy 才能从现金扣）
3. `.s-debt` 样式：灰白斜纹 → **红色斜纹**（opacity .95），负债段一眼可见
4. `fly()`：借钱发生时 toast「💳 借到 ¥x，已记进负债」
5. 删掉 borrow 里的 `equity/cost/trades/neverBought` 副作用——「一次都没动」结局判定反而更准（纯借钱不算动过仓）

## cards.json 配套（5 张）
借来就炒股的补 `buy`（钱到现金→立刻买入，行为与旧版等价但过程可见）：
- fam_eldermoney_01「收下，投进去」/ risk_margin_01「先配 12,000」/ risk_loanad_01「借 12,000 抄底」/ risk_callmargin_01「再借 5,000 补上」
- risk_card_01「还最低」：`borrow:8000`（语义错乱：还账单怎么会借新钱买股）→ `repay:3000`（真还 3000，债真的少了）

## 验证
- validate 148 张全绿 / 伪选择 0% / 重复 0% / sync 原型同步 ✓
- 3k 随机（seed 20261024，data/sim/sim-20261025-borrow-rework.json）：随机通关 33.5→33.0% 持平；
  穿仓 13.3→15.2%、一无所有 7.4→9.3%（乱滑玩家借钱不买、利息白滚，合理漂移）；爆了 2.1→1.3%
- check-policy：技巧回报 x1.63→**x1.73**（更接近 2.0 目标；彩礼借的钱进现金后 spend 不再砍仓，策略更顺）

## 教训
borrow 旧语义「借钱=直接满仓」是把两个动作（借钱、买入）焊死在一个键里——
玩家看不见任何一个。拆开后卡片用 `borrow+buy` 表达「借了就投」，语义清晰且每一步都可见。

## 精力系统：第四条属性上线（金钱挪进行情区）

### 用户决策
「金钱属性改成精力——陪伴类卡片消耗的就是精力；金钱数值用中间的现金/持仓/负债展示，不重复。」

### 改动
1. **HUD**：金钱行 → 精力行（青绿条，<25 警戒闪烁）；金钱三段条（现金橙/持仓红/负债红斜纹）整体搬进中间行情区（净值大字下方 5px 细条），上一轮的负债可视化保留
2. **结算**：`apply()` 新增 e.energy；花精力选项当场扣，**当天已花精力则今晚恢复打折**；见底还硬撑 = 心态 −10 + 当天提示；见底期间每天心态 −2
3. **恢复**：每天 +4，花过精力的天 +2（三档试出来的：+9/+4 时全投入玩家也永不见底、+6/+3 依然宽裕，+4/+2 才形成约束）
4. **卡池 54 个选项打标**：
   - 花精力（45）：陪伴/约会 −6~−16、见家长/提亲/陪护/连夜医院 −20~−26、婚礼 −32/−28、私活 −28/−26、加班 −18、应酬 −12~−14
   - 回血（6）：睡了 +20、扣下手机 +16、今晚不看了 +18、吃药早睡 +15、手机扔客厅 +14、准时走 +10
   - 「自己」类休息卡天然构成精力经济的回血侧，闭环成立
5. **配套工具**：validate（键白名单 + 范围 ±35 + 精力消耗算代价 + 支配检测加维度）、check-policy（vec 加 energy；maximin/会玩策略均感知精力——诚实原则）、build-manager NUM_EFFECTS + energy（41 列）
6. **when 条件**：energy 可用于表达式（如 `energy<20`），原型/快版过滤器自动支持

（p50/p5/见底天数/花精力次数），按「随机谷值 72 不挨打、全投入谷值 38 偶见底」校准参数。

## 精力改为「预算制」：初始 50、零自然恢复（用户：「精力一直满，难度太低」）

### 改动
1. 初始精力 100 → **50**（开局就是半管，条上一眼看出余量不多）
2. **删除每天自然恢复**（原 +4/天、花过精力 +2）：精力不再随时间回血，只能靠卡片回血侧（睡了 +20、不看盘 +18、放下手机 +16、早睡 +14、体检 +15/+18、准时走 +10）

4. 见底惩罚同步放轻（没有自然恢复后，原惩罚会滚成心态死亡螺旋）：
   - 见底期间每天心态 −2 → **−1**；精力 0 还硬选花精力选项 −10 → **−6**

## Bug 修复：没借钱却抽到还钱卡（用户线上反馈）

### 根因（两个叠加）
1. `risk_card_01`（信用卡账单）没挂 `when` 条件——零负债也会抽到
2. `spend()` 现金不够时**默默自动记负债**（砍仓→差额进 debt，只扣 3 社会），玩家「没主动借钱」但早就被动欠了，之后 debt>3000 的还钱卡名正言顺出现，玩家只觉得莫名其妙

### 修复
1. `risk_card_01` 挂 `when: debt>0`
2. 被动欠债与主动借钱分开提示：主动借「💳 借到 ¥x」、被动欠「💸 现金不够，欠下 ¥x」、还款成功新增「✅ 还掉 ¥x，负债减少」
3. validate-cards 新增规则：**卡面含 repay 必须 when 带 debt 条件**（防回归）

### 验证
148 张全绿、1k 快速仿真正常。engine 的 repay() 本就有零负债保护（pay=0 直接返回，不扣钱）。

## 新手可读性改造（用户拉了个没接触过游戏的人试玩）

1. 不知道游戏目标是什么
2. 卡片文案常不按正常人说话的逻辑来，省略语意缺失，读不懂

### 修复 A：开局说明弹窗（新增）
- 刷新页面必弹《韭菜之王》说明卡，点「开始第一周」进入游戏，内容三段：
  ① 目标：打工人 18,000 元进场（一半是底仓）、工资每 15 天 6,500、撑过 60 天、净值（现金+股票−欠款）尽量多
  ② 玩法：每天一张卡，右滑=照做/投入、左滑=拒绝/抽身；买卖都藏在卡片选项里
  ③ 四条命：精力/心态/社会归零、穿仓、爆仓任一即结束；生活每天花钱
- 页脚过时的平衡数据（600 局 16%）更新为当前口径

### 修复 B：20 张卡文案重写（逐张过完 148 张后的重灾区）
通则：一遍读懂（谁+发生什么+要我选什么）、不用没有前情的指代、黑话当场解释、梗要落点。
- 梗依赖：年度账单「跑赢了 1.2% 的人」→「98.8% 的人收益都比你高」；「账户绿了」→「一片绿色，又亏了一天」
- 无前情指代：「对方已读，没有回」→「投出去的简历，五份全都已读不回」；「有人凑到耳边说了几句」→ 明说透了一只必涨的票
- 文艺省略：「像某种预兆」「那根线还在跳」「更喜欢那根线」「今天的线」→ 全部改为直说（行情曲线/股票和你哪个重要）
- 黑话：止损位击穿/改止损位 → 「到价就卖的线」；基金清盘 → 补「钱亏着退回来」；催消费贷 → 「到还款日，催收短信」
- 缺动作语境：「卷子」→「考卷等你在家长栏签字」；「就这样走下去」→ 求婚语境
- 住嘴校验：fam_queding_01 正文剧透选项原文、mkt_bear_fund_01 超 31 字——被 validate 拦下后已修
