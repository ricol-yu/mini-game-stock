# 常驻角色名单（N2 批 1 前置 · 待用户审定）

> **为什么需要这份名单**：现在 48 个角色里 39 个只出场 1 次——等于 39 张一次性卡。
> Reigns 的黏性来自「同一个讨厌的顾问又来了」，同一个角色反复出现、前后态度有变化，
> 玩家才会对他产生记忆。N2 要铺的 157 张卡，大部分应该挂在下面这 20 个人身上。
>
> 20 人 × 6–10 张 ≈ 120–200 张，正好覆盖扩容量。名单外的角色仍可作为一次性事件出现。

### 不做常驻的

- **你的猫**（`mao`，意外类唯一一张）：意外就该是意外，猫可以偶尔回来，但不固定排班
- **老师 / 同学 / 老同学 / 饭局 / 微信群 / 券商短信 / 网友 / 年度账单 / 银行**：留作一次性事件，穿插调剂
- **意外 tag 的原则**：不挂常驻角色，走随机池，保证「不知道会发生什么」

## 给 N2 写卡的用法

1. 每张新卡的 `who` + `whoId` 必须来自这份名单（或明确标注为一次性角色）
2. 同一角色的新卡要**接得住旧卡**：老婆在 `fam_pregnant_01` 里生了孩子（`addst: baby`），
   后续老婆卡里就该有孩子出生后的状态（`when: has:baby` 的分支卡——DSL 谓词引擎 N3 实装，先写好备用）
3. 每人 6–10 张里，至少 2 张带 `when` 条件，让角色随玩家状态变化——这是「熟人感」的技术载体
