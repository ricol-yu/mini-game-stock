# UI 正式版改造方案（v1）

> 2026-10-28 · 基于 prototype v3（单屏流：片头 → 序幕 → 主循环 → 结局）盘点后重设计。
> 原则：**玩法骨架不动**（滑动决策、HUD、资金条、卡牌流全部保留），补齐"游戏该有的壳"。

## 1. 现状盘点

| 已有（保留/重构） | 缺失（新增） |
|---|---|
| 片头标题屏（一个「开始」按钮） | **主菜单**（新开局 / 继续 / 图鉴 / 设置） |
| 序幕教程卡 ×3（滑动教学） | **设置页**（音效/音乐/文字速度/重开） |
| 主循环：HUD 四条命 + 胶囊条 + 资金条 + K 线 + 卡牌舞台 + toast | **存档/续玩**（退出后接得上） |
| 结局面板（结局文案 + 为什么 + 一生数据） | **图鉴/结局收集**（11 个结局，全靠玩家自己撞） |
| 悬崖预警、飘字、胶囊 tooltip | **复盘时间线**（结局页只给结果，不给过程） |
| | **弹窗系统**（现在是 toast 单行文字，放不下复杂信息） |
| | 音效/BGM 的挂载点（完全没有） |

## 2. 界面结构总览（改造后）

```
主菜单 (menu)
├─ 继续（有存档时显示：第 N 天 · 净值 · 主角状态缩略）
├─ 新开局（有存档时需二次确认：当前进度将被覆盖）
├─ 图鉴 (gallery)
│   ├─ 结局收集：11 格，点亮已达成，未达成显示剪影 + 一句提示
│   └─ 结局详情：达成过的可回看完整文案与达成条件（隐藏数值细节）
├─ 设置 (settings)
│   ├─ 音效 开/关　音乐 开/关
│   ├─ 文字速度（toast/飘字停留时长）
│   ├─ 左右手习惯（滑动提示方向互换）
│   └─ 删除存档（二次确认，输"确认"两个字才生效）
└─ 关于（版本号、制作说明、红线声明"本游戏不构成投资建议"）

游戏内 (game) —— 单屏结构不变，只重构内部
├─ 顶部 HUD（重构：四条命 → 图标化紧凑条，容纳更多胶囊）
├─ 胶囊条 strip（保留：还款倒计时/状态/老赖红标）
├─ 资金区 mkt（重构：净值+资金条+K线，加"月账单预览"入口）
├─ 卡牌舞台 stage（保留：滑动手势、fact 卡、预警）
├─ 暂停按钮（新增，右上角）：呼出
│   └─ 暂停弹窗 (pause)：继续 / 设置 / 回主菜单（自动存档）
└─ 弹窗层 modal（新增，替代部分 toast 场景）
    ├─ 结算明细弹窗：现金不够→欠债时，一笔账列清楚（借了多少/月供多少）
    ├─ 月账单弹窗：每月 5 号结算后可点开：工资/房租/月供/划扣 分行列出
    ├─ 大事件弹窗：清算卡、老赖上身、结局前夜——复用卡面人物位（640×400，不做整屏立绘）
    └─ 通用确认弹窗：新开局覆盖存档等

结局 (over，重构)
├─ 结局卡面：结局插图（可选，第三批素材）+ 结局名 + 文案（现在的内容全部保留）
├─ 一生数据（保留：天数/收益/最大回撤/交易次数…）
├─ 时间线（新增）：关键节点回放——按天记录的大事（结婚/清算/爆仓/最大单日盈亏）
└─ 操作：再看一遍时间线 / 回主菜单 / 直接再来一局
```

## 3. 模块清单：新增 / 重构 / 保留

### 新增（6 个）
| 模块 | 内容 | 复杂度 |
|---|---|---|
| 主菜单 | 继续/新开局/图鉴/设置/关于 | 低 |
| 设置页 | 四个开关 + 删除存档 | 低 |
| 存档系统 | 单局自动存档（每日结算后写一次），进游戏即续 | 中 |
| 图鉴 | 结局收集 11 格 + 详情回看 | 中 |
| 弹窗层 | 结算明细 / 月账单 / 大事件 / 通用确认 | 中 |
| 暂停菜单 | 继续/设置/回主菜单 | 低 |

### 重构（3 个）
| 模块 | 改动 |
|---|---|
| HUD | 四条命图标化 + 数值条二合一，腾出空间给暂停按钮；胶囊条可横向滚动（状态多了现在会挤） |
| 结局面板 | 加时间线；结局页配 2–3 张关键结局插图（第三批素材，缺了用现有文字排版） |
| toast | 拆两类：轻提示保留 toast，重信息（欠债明细/月账单）走弹窗 |

### 保留不动（6 个）
卡牌舞台与滑动手势 · 序幕教学 · 资金条/K线 · 飘字 · 欠账计数隐藏机制 · 老赖/逾期红标

## 4. 页面流转

```
启动 → 主菜单 ──继续──→ 游戏（读档）
         │                │
         └──新开局──→ 序幕教程 → 游戏 ──暂停──→ 暂停弹窗（可去设置）
                          │                      │
                          每日结算自动存档        回主菜单（存档保留）
                          ↓
                        结局判定 → 结局面板（时间线）→ 主菜单（存档清空，图鉴点亮）
```

## 5. 实现顺序建议

1. **弹窗层**（其他模块的地基，modal 组件先立起来）
2. **存档**（localStorage 单局档 → 主菜单「继续」才有意义）
3. **主菜单 + 设置**（壳搭好）
4. **图鉴 + 结局面板时间线**（内容型，随素材进度走）
5. HUD/资金区视觉重构（等美术素材到位一起换肤，避免做两遍）
