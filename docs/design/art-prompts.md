## 0. 30 秒上手

## 1. 全局配方（每条提示词都以此开头）

### 1.1 场景风格句（10 张逐字相同，不许改写）

```
扁平厚涂插画，游戏卡牌场景；暗暖色调，单一主光来自画面左上方 45°（暖黄 3200K）；
中景清晰、背景柔和虚化，景深画在画面里；明度偏低不透亮（上部亮、中部中、地面压暗）；
饱和度中等偏低，不超过 62%；无任何文字与招牌字，屏幕只显示抽象色块与曲线，不出现清晰人脸；
竖向 8:9，中央竖向留出低对比空间供人物站立，重要元素不出画面左右各 6%。
```

### 1.2 全局负面提示词（同样每条都带）

```
文字, 汉字, 英文, 数字, 水印, logo, 品牌标识, 真实 App 图标, 股票代码, 清晰人脸, 正脸特写,
变形的手, 六指, 过曝, 荧光色, 赛博朋克, 霓虹紫, 高饱和撞色, HDR, 摄影写实, 3D 渲染,
玻璃强反光, 杂乱前景, 签名, 边框, 白边, 人物
```
> 唯一例外：`banquet`、`street_night` 允许虚化人群，这两张把负面词里的「人物」改成「清晰五官的人物」。

### 1.3 为什么这些参数是死的

| 参数 | 值 | 原因 |
|---|---|---|
| 画幅 | 8:9（640×720） | 卡面图区 309×350，比例 0.883，8:9=0.889，`cover` 裁切 <1% |
| 主光 | 左上 45°、3200K | 所有场景统一，人物轮廓光才站得住（`art-spec §1.4`） |
| 明度 | 上 82 / 中 58 / 地面 34 | 地面必须压暗，人物才"立"得住 |
| 留白 | 中央竖向 35%~65% | 人物锚点在中央，脸在 28% 高度（`art-spec §1.3`） |
| 无文字 | 硬约束 | 卡面正文才是文字主体；也是合规要求 |

### 1.4 裁切安全框（按 8:9 出图，但要活过 4:5 与极端宽幅）

同一张图会被三种画框裁，构图必须**一次同时满足**：

| 画框 | 何时出现 | `cover` 怎么裁 | 构图要求 |
|---|---|---|---|
| **8:9**（基准） | 390 档 309×350，比例 0.883 | 上下各裁 <1%，等于不裁 | 按提示词原样画即可 |
| **4:5**（0.80，更窄更高） | 分享图 / 窄屏 / 未来竖版位 | **左右各裁 5%，纵向不裁** | 脸、关键道具、人物双手不越出**中央 88% 宽**；§2 已统一按左右各 6% 留 ✔ |
| **极端宽幅**（≥1.4:1） | 系统大字号 `.art` 让位（309×96）、320 档降级（266×181） | `object-position:50% top`，**只留顶部 27.6% / 60.5%** | 顶部这条带必须自洽：脸完整落在 **y 16%~34%**，横穿这条带的地方只放背景，不许有关键道具 |

一句话记法：**横着裁只裁到 6% 边，竖着裁只留上面一截**——所以「中间站人、上部有脸、边上别放东西」。

> 320 档（266×181）大腿以下被裁，属预期、不影响可读；大字号档只留 27.6%，最容易切掉下巴，
> 验收时单独把成品缩到 309×96 看一眼（§5 第 6 条）。

## 2. 十张场景（每张一段，直接复制）

> 统一的构图约定：**中央 x ∈ [35%, 65%] 从 y=12% 到 y=95% 留低细节/低对比空间**（人站在这），
> 细节压在左右两侧；**人物头顶之上（y<16%）不放物体**；**地面接缝线画在 y≈88%~94%**，让人物脚底有落点。

## 4. 一致性保障（同一角色 / 同一套场景不跑偏）

### 4.1 五次实操要点

1. **固定种子**：同角色所有差分用**同一个 seed**，只替换表情句；跨批次出图也沿用这个 seed。
   场景 10 张如果同一模型支持，也用同一 seed 起步（先出 S1，把 seed 记下来）。
2. **先出角色三视图再定稿**：第一版先让模型出「正面 / 3/4 / 侧面」三张拼图，
   选定一张作为该角色的**标准脸**，之后所有图都以它为参考图（image reference / IP-Adapter / 角色锁）。
3. **参考图优先于文字**：角色锁定后，提示词里只保留变化的部分（表情/动作），
   设定段可以缩短——**参考图负责"像不像"，文字负责"画什么"**。
4. **提示词不许同义改写**：全局句逐字复制。改写会改变模型对画风的权重，10 张就会分裂成 2~3 套风格。
5. **一次只出一个角色或一个场景**：不要在一个 prompt 里塞两个角色；批量时按「同角色连续出」排队，
   避免模型在角色之间漂移。

### 4.2 常见失败与修法

| 症状 | 修法 |
|---|---|
| 场景里出现文字/招牌字 | 负面词加重「文字, 汉字, 招牌」；提示词里把"屏幕"改成"纯色方块与抽象曲线" |
| 人物被"拍"进背景（抠不出来） | 背景必须是纯 #DCDCDC，负面加「场景/家具/阴影」；光比压低，不要逆光 |
| 同一角色两张脸不一样 | 换回参考图模式 + 固定 seed；先把三视图定稿再出正式图 |
| 人物尺寸/位置不一 | 提示词末尾固定写「头顶在画面上方 16%，人高约占 78%，脸心 28%」，出图后按 §5 量 |
| 地面太亮，人物"浮" | 提示词强调「地面压暗、明度最低」；后期可在合成层加 shade 救，但先修图 |
| 风格偏写实/3D | 负面加重「摄影写实, 3D 渲染, 景深镜头」；正面句强调「扁平厚涂、笔触可见」 |
| 差分表情不像同一个人 | 只改神态句，别改光照/角度/服装；同一 seed + 参考图 |

## 5. 出图后验收清单（9 条，逐条打勾）

| # | 检查项 | 标准 |
|---|---|---|
| 1 | 尺寸 | 640×720（8:9）；高清图按比例缩，**不许非等比拉伸** |
| 2 | 透明（仅人物/剪影） | 真 alpha 通道（导出 WebP 后查 `ALPH` chunk，或设计软件里看棋盘格）；边缘无白边/黑边 |
| 3 | 头部锚点 | 头顶 y=118 ±8；脸中心 (320, 202) ±8；脸宽 140 ±12 |
| 4 | 底部基准 | 脚底（或半身裁切处）y=678 ±8；人高 560 ±20 |
| 5 | 留白 | 场景中央 x∈[35%,65%] 无高对比元素；人物叠上后不压任何关键道具 |
| 6 | 裁切安全 | 关键元素在中央 88% 宽内；把成品缩到 **309×96** 看一张，脸还认得出、下巴没被切掉（§1.4） |
| 7 | 明度/色温 | 同批并排看：无一张发灰或过曝；地面区明显暗于中部；10 张色温一致 |
| 8 | 体积 | 场景 ≤45KB、人物 ≤38KB、差分 ≤36KB、剪影 ≤10KB（WebP q80） |
| 9 | 合规与命名 | 无文字/无品牌/无清晰人脸；文件名严格按 manifest（`scene_<key>.webp`、`<whoId>[_<emo>].webp`） |

> 7 与 9 不过关直接重出，不要靠后期修：这两项修不回来。

## 6. 建议出图顺序（先 3 张试水，再批量）

**第一批试水（3 张场景 + 1 个角色）**：

| 顺序 | 出哪张 | 为什么先出它 | 验证什么 |
|---|---|---|---|
| 1 | `living_night` | 42 卡，覆盖最广（25% 的卡用它） | 整体色调与明度体系是否成立 |
| 2 | `trading_desk` | 38 卡，游戏主题最强 | 「屏幕只出色块 + 曲线」这条硬约束能不能守住 |
| 3 | `banquet` | 9 卡，暖红金最考配色 | 与上面两张并排看，是不是同一套画风（灯笼调最易跑偏） |
| ＋1 | `laopo` base + `worry` | 32 卡、曝光最大，且有 4 个差分 | 抠图质量、锚点、差分是否同脸 |

这三张场景 + 一个角色并排看：**如果色温、笔触、明暗关系一致，就锁死 seed 和风格句，批量出剩下 7 张场景**；
如果不一致，先调全局风格句（不是逐张调），重出这 3 张，直到它们像同一个画师画的。

**接着**：剩余 7 张场景 → `laopo` 另外 3 个差分 → 高频角色（`laoma` / `haizi` / `laoban`）→ 其余 8 个角色。
