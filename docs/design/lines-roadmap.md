## 二、父母线

**主题：你嫌他们烦的电话，总有一天会停。**

路径：`(日常)` momcall_01 吃了没 → `[投入检查点]` 接不接电话 → `(回响)` momcall_02 菜市场听见她叹气 / momhealth_01 血压单 → `[小清算]` momhealth_02 复查稳住（补品 2,000） / `⟦大清算⟧` hospital_01/02 爸住院（6,500 / 9,000，双 miss 才触发重版）

**深化新增（+2 张）**：
- `[养老抉择]` fam_eldercare_01（day 40+, did:hospital 链后）：他们真老了，接来住 / 请护工 / 每月寄钱——三种代价：social/mind/cash 各占一头
- `⟦风不止⟧` fam_momgone_01（**隐藏重卡**）：全程 miss≥3 且 day>50——「妈的电话不会再来了」social-15, mind-15，不出现在任何提示里，只有亏欠的人才遇见

**→ 结局**：social 低位 → 没有人；大清算 spend/borrow → 穿仓；全程亏欠 → 风不止直压「不动了」。

## 六、市场线（状态驱动）

**主题：行情不杀你，是行情里的你杀你。**

状态弧线：`平静开局` → 政策卡开**牛市**（bull_open）或**熊市**（bear_open，day>8） → 牛市可滑入**泡沫**（bubble_01 / fomo / paperwin） → 熊市可加深**冬天**（crisis_01 / panic） → 停牌支线（halt）穿插任意熊段 → policy_whim 政策反复横跳

**深化（+2 张滑入卡）**：
- mkt_bull_to_bubble_01：牛市里「专家说这次不一样」（加速泡沫滑入）
- mkt_bear_to_crisis_01：熊市里「隔壁券商爆雷了」（加速冬天滑入）

**→ 结局**：**泡沫之后**（破后10天净值<9000）、**冬天还没过完**（crisis+破产）直接归属；牛市杠杆 → 爆了；其余结局的行情背景板。

## 七、风险线（债务螺旋）

**主题：每一个深渊的入口，都写着「利息很低」。**

螺旋：`入口` loanad 20,000 / margin 十倍杠杆 → `(加重)` scam 8,888 / influencer 闭眼买 / leak 内幕 → `[追保]` callmargin（debt>8000） → `[纠偏机会]` repay_01 / dca_01 定投 → **🆕 以贷养贷** risk_roll_01（debt>15,000 新增）：「B 口子借来还 A 口子，只差三天」borrow 更多 → 无解滑落

**→ 结局**：**爆了**（risk100）、**穿仓**（n≤0 且 debt>5000）、**最后一把**（over+risk55）、**一无所有**——本线是这四个结局的唯一或主要来源。

## 惩罚卡总表（每条线至少一张「欠账清算」——数值控制的抓手）

设计原则：**每条线都必须有牙齿**。玩家持续忽视某条线，该线就在游戏后期收账，无预警、由结局面板死因区解释。这样各线的社交/心态消耗可控，不存在「白嫖线」。

|---|---|---|---|
| 伴侣线 | 离婚（已有，改造触发条件） | 婚后 miss≥3 且心态<35 | 社交 −20（全游戏最重） |

| 父母线 | 🆕 妈的电话不会再来了 | 敷衍父母≥3 次且 day>50 | 社交 −15 / 心态 −15 |
| 子女线 | 🆕 孩子毕业典礼那天你在看盘 | 陪伴 miss≥3 且 day>48 | 社交 −12 / 心态 −10 |

| 职场线 | 裁员链（已有 6 张，day 18–30） | 怠工记账 | 失业状态 → 现金流断 |
