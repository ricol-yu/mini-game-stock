# 美术素材规范（v1）

> 2026-10-28 · 配套《UI 正式版改造方案》。设计基准：手机竖屏 375×812 逻辑像素，
> 资源一律按 **@2x 导出**（设计稿宽 750px）。微信小程序环境下 WebP 仅部分机型支持，
> 保守起见：**透明图用 PNG，不透明大图用 JPG，图标用 SVG**。

## 1. 通用规格

| 类别 | 格式 | 尺寸（@2x 导出） | 备注 |
|---|---|---|---|
| 人物头像（卡面用） | PNG-24 透明 | **240×240**，主体占 80%，圆框内显示 | 当前卡面头像位是圆形 |
| 人物立绘（大事件/结局卡） | PNG-24 透明 | **750×1000**，半身，底部留 80px 安全区 | 清算卡/结局/老赖上身等整屏卡面 |
| 表情差分 | PNG-24 透明 | 与对应立绘/头像同尺寸，**脸部区域各表情完全对齐** | 只换五官不换姿势，切换不跳帧 |
| UI 图标（四条命、按钮、胶囊） | SVG 源文件 + PNG @2x | 48×48（线条 3px） | 单色优先，两态：普通/告警（红） |
| 背景 | JPG q80 | **750×1624**（整屏） | 主菜单、序幕、结局通用底图 |
| 卡面场景底图（情境卡） | JPG q80 | 750×420 | 新闻/银行/交易所等，上面压半透明文字层 |
| 结局插图（11 个） | JPG 或 PNG | 750×1000 | 图鉴里也要用，统一比例 |
| BGM | MP3 128kbps | 循环时长 60-120s | 需无缝循环 |
| 音效 | MP3 128kbps | ≤ 2s | 短促干净 |

## 2. 命名规则

```
char_<角色id>_<表情>.png        人物素材：char_laopo_normal.png
expr_<角色id>_<表情>.png        差分脸：expr_laopo_sad.png
illu_<结局id>.png               结局插图：illu_shore.png
bg_<场景>.jpg                   背景：bg_menu.jpg / bg_night.jpg
scene_<情境>.jpg                情境卡底图：scene_news.jpg
ico_<名称>[_alert].svg          图标：ico_mind.svg / ico_mind_alert.svg
ui_<模块>_<元素>@2x.png         UI 件：ui_menu_btn_start@2x.png
bgm_<场景>.mp3 / sfx_<动作>.mp3  音频
```
角色 id 一律沿用 `data/cards.json` 的 `whoId`（laopo / laoma / haizi / laoban / nidemao…），
**不新造命名**，代码里零映射成本。表情用英文小写：normal / happy / angry / sad / worry / cry / shock / smug。

## 4. 风格约定（给你和画师对齐用）

- 现有气质是**冷淡白底 + 黑字 + 邮票印章**（红涨绿跌），偏「账本感」。美术建议走
  **低饱和扁平插画风**，人物小比例、留白多，别用浓艳游戏风——会跟文案气质打架。
- 卡面文字永远是主体，**立绘/头像不许带文字、不许抢对比度**（头像区当前是 40% 透明度压暗）。
- 猫是唯一可以画风略「萌」的例外。
- 红涨绿跌是中国股市惯例，素材里涉及涨跌颜色一律红=涨、绿=跌。
