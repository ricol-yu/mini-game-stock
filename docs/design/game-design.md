# 玩法规格 · 韭菜之王 v3

> 本文从 `prototype.html` v3 反推，把散在代码里的数值规则写成文字。
> **`data/cards.json` 是唯一真源**（`prototype.html` 由它生成），本文与之不一致时以真源为准，
> 并回来修正本文。
> 目的：让两台设备、两个 AI 对同一套规则有同一份理解。

## 一句话

你一辈子只有一只票，它甚至没有名字。60 天里，每天一张卡，左滑抽身、右滑投入。
钱、心态、风险、社会四条线同时走，任何一条崩了，人生就提前结束。

## 核心循环

```
抽 3 张卡 → 弹出最上一张 → 玩家左右滑动 → 结算这张卡 →
每日行情推进（tick）→ 检查是否结局 → 天数 +1 → 下一张
```

一天 = 一张卡 + 一次 tick。上限 60 天。

## 四属性

| 属性 | 初始 | 范围 | 归零/触顶后果 | 作用 |
|---|---|---|---|---|
| 金钱 net | 18000 | 可为负 | `net <= 0` 触发破产类结局 | 现金 + 持仓 − 负债 |
| 心态 mind | 58 | 0–100 | `<= 0` 结局「不动了」 | 波动影响它；`>= 88` 进入「上头」 |
| 风险 risk | 0 | 0–100 | `>= 100` 结局「爆了」 | 放大持仓波动（1x–3.4x），抬升利息 |
| 社会 social | 56 | 0–100 | `<= 0` 结局「没有人」 | 人脉、家庭关系；高社会值反哺心态 |

**金钱是复合的**：`net = cash + equity − debt`。
现金是活钱，持仓是会波动也会归零的钱，负债每天计息且放大风险。

## 每日结算引擎

按代码执行顺序，依次做这些事。顺序影响结果，实现时不要调换。

### 1. 行情漂移

```
drift = 0.003 + sin(tickCount / 14) × 0.024
泡沫期 drift += 0.028
危机期 drift -= 0.024
```

`0.003` 是长期微涨（时间站在耐心的人一边），`sin(cyc/14)` 制造约 88 天周期的牛熊（一个 60 天的局大约经历半个周期，玩家读得出趋势但不至于背下来）。

### 2. 指数波动

```
vol = 0.030 × (危机 ? 1.7 : 1) × (泡沫 ? 1.4 : 1)
r   = drift + (random() − 0.5) × vol
内线状态：r += 0.014
指数 = 指数 × (1 + r)          // 初始 3000
历史序列保留最近 40 个点
```

### 3. 持仓波动（关键：风险在这里生效）

```
放大倍数 m = 1 + risk / 42          // 风险 0 → 1x，风险 100 → 3.4x
持仓收益 sr = r × 1.3 × m + (random() − 0.5) × 0.018
持仓 = max(0, 持仓 × (1 + sr))
```

`× 1.3` 是杠杆感——你那只票比大盘更凶。持仓可以归零（`max(0, …)`）。

### 4. 心态随波动摆动

按持仓当日涨跌幅 `pct` 判定：

| 条件 | 心态变化 |
|---|---|
| `pct < −6%` | −3.5 |
| `pct < −2%` | −1.2 |
| `pct > +3%` | +1.6 |

空仓时不触发（与你无关）。

### 5. 状态结算（见下一节）

### 6. 债务与自然衰减

```
利息 = 负债 × 0.0015 × (1 + risk / 70)     // 风险越高，钱越贵
现金 -= 利息
risk   -= 0.15                             // 风险消退得很慢
social -= 0.22                             // 人情是会淡的
重仓时（持仓 ≥ 总资产 75%）risk += 0.45    // 重仓本身就是风险
mind   += 0.55 + (social >= 70 ? 0.35 : 0) // 心态每天缓慢回血
```

这组数字定义了游戏的**基调**：风险消退 0.15/天，但重仓每天涨 0.45——重仓三天就抵消五天的自然消退。社会值每天掉 0.22，60 天掉 13 点，不管不问就会疏远。

## 状态系统（Buff / Debuff）

| key | 名字 | 持续 | 每日效果 | 解除方式 |
|---|---|---|---|---|
| `bubble` | 泡沫 | 动态 | 漂移 +0.028，波动 ×1.4 | 破裂（见下） |
| `crisis` | 冬天 | 12 天 | 漂移 −0.024，波动 ×1.7，心态 −1.3 | 倒计时 |
| `halt` | 停牌 | 5 天 | 价格冻结、不能卖出、心态 −0.8 | 倒计时 |
| `baby` | 添丁 | 永久 | 现金 −180/天，心态 +1.0，社会 +0.4 | 不可解除 |
| `fired` | 失业 | 永久 | 心态 −1.1/天 | 特定卡（老同事） |
| `insider` | 内线 | 6 天 | 收益 +0.014，风险 +1.4/天 | 14% 概率/天崩掉 |
| `over` | 上头 | 动态 | 心态 −0.5，风险 +0.3；买入量 ×1.35 | 心态 < 74 自动解除 |

**泡沫破裂**（这是全场最刺激的机制）：

```
p = 0.09 + 0.05 × 泡沫已持续天数
若 random() < p 或 持续 >= 14 天：
    持仓 ×= (1 − (0.30 + random() × 0.28))   // 跌 30%~58%
    心态 −14
    记录 burst / burstDay / burstDrop（供结局判定）
```

期望寿命约 8 天，最长 14 天。玩家永远不知道哪一天是最后一天。

**内线崩塌**：每天 14% 概率。崩了则清除状态、风险 +16、心态 −10、社会 −5。
期望 7 天，恰好等于状态时长——大部分时候你等不到兑现。

**上头自动触发**：`mind >= 88` 进入，`mind < 74` 解除。进入后买入量 ×1.35，
且「上头 + 高风险 + 破产」会触发专门的结局。这是唯一一个由属性驱动的状态，
设计意图是「你以为自己很冷静，但你已经在多买了」。

## 卡牌系统

### 结构

```js
{
  who: "老婆",                    // 谁
  av: "💍",                       // 头像
  tag: "家庭",                    // 分类
  txt: "这个月房贷 6,800。你看着办。",
  when: function(){...} | 缺省,   // 触发条件（缺省=随时可出）
  st: { halt: 5 } | 缺省,         // 无论选哪边都会发生的状态
  L: { s: "先拖两天", e: {...} }, // 左滑：抽身 / 拒绝
  R: { s: "出 5,500", e: {...} }  // 右滑：投入 / 认了
}
```

### 效果字段

| 字段 | 含义 |
|---|---|
| `buy: n` | 用现金买 n，转入持仓，成本 +n |
| `sell: r` | 卖掉比例 r（0–1），先还债，风险下降 |
| `spend: n` | 花钱，现金不够则自动卖持仓补，仍不够则转为负债 |
| `borrow: n` | 借钱买股：负债 +n、持仓 +n、风险上升 |
| `repay: n` | 还债：现金减、负债减、风险下降 |
| `cash / equity / cost` | 直接增减（绝对值） |
| `mind / risk / social` | 属性增减 |
| `addst: {key: 天数}` | 开启状态，`-1` 表示永久 |
| `unst: ["key"]` | 解除状态 |

### 抽取规则（2026-10-21 从「独立等概率」改成「洗牌袋」）

```
一轮洗一副牌：全池每张卡各一张，按类型分层交错（同类被摊开）
每回合从袋头取第一张「 satisfy when 且 没到 2 次上限 且 不在最近 10 张里」的卡
袋空 / 袋里没有能出的 → 重洗一轮（重洗时同样跳过最近 10 张）
全池都到 2 次上限 → 清零使用次数重开（正常一局碰不到）
垫在下面两张是「预览」：读袋不取袋，不消耗也不计数
```

**为什么不用真随机。** 独立等概率（iid）有个反直觉性质：一局 76 次抽卡里，
「刚打完又抽到同一张」必然发生 2~3 次，同类卡连着来占 16%。玩家读作「卡不够 / 老是这一张」，
这不是 bug 而是随机的本来面目。人的直觉期望是「均匀铺开」，所以这里不用 iid，用袋子。

**分层交错**把同类卡在袋子里的间距摊平：家庭 25 张约每 4 张一次、决策 3 张约每 32 张一次，
交错后相邻两张几乎不可能同类。代价是同类出现的**节奏变规律**（每 4 天一次家庭），
所以「某一类太多」只能靠**加卡**解决，不能靠抽卡算法掩盖。

实测（`node tools/check-repeat.js --compare`，1500 局）：

| 指标 | 旧（iid） | 新（洗牌袋） |
|---|---|---|
| 同一张卡连着来 | 0.95% | **0%** |
| 同一张卡 5 步内再来 | 3.70% | **0%** |
| 同一类卡连着来 | 15.51% | **0%** |
| 一局内出现重复卡 | 87.1% 的局 | **0%** |
| 单张卡一局最多出现 | 3 次 | **1 次** |
| 三张叠牌里有重复 | 3.16% | **0%** |

一个副作用值得记：**卡池 ≥ 一局天数（60）时，一局之内不会有任何一张卡重复**。
97 张对 60 天是宽裕的，所以「再加卡」不再能改善单局重复 —— 它买到的是重玩差异。

## 结局系统

按代码里的判定顺序，**先命中先结束**：

| 优先级 | 条件 | 结局 |
|---|---|---|
| 1 | 泡沫破裂后 10 天内、净资产 ≤ 初始 50%、且跌幅 > 42% | 🫧 泡沫之后 |
| 2 | `risk >= 100` | 💥 爆了 |
| 3 | 上头状态 + `risk >= 55` + `net <= 0` + 负债已满额度 | 🎈 最后一把 |
| 4 | `net <= 0` + 负债已满额度 + 危机状态中 | ❄️ 冬天还没过完 |
| 5 | `net <= 0` + 负债已满额度 | 💀 穿仓 |
| 6 | `mind <= 0` | 🧊 不动了 |
| 7 | `social <= 0` | 🪑 没有人 |
| 8 | `net >= 80000` | 🪙 自由 |
| 9 | 60 天满且一次没买 | 👁 一次都没买 |
| 10 | 60 天满且已婚（办过婚礼）且社会 ≥ 70 | 🏠 两个人 |
| 11 | 60 天满且收益率 ≥ 60% | 🏆 六十天（还站着） |

**`net <= 0` 本身不是死因（2026-10-28 用户定）**：钱花光可以借，先欠着继续活。
真正的死线是**负债顶到信用额度**（`creditLimit()` = 两个月工资 19,800，失业打三折），
那时候没人再借你，才是穿仓。原「🧾 一无所有（`net<=0`）」结局因此删除——
它描述的场景现在一律走"继续借"这条路。

老赖（`st.laolai`，月供还不上就当次上名单）**不砍额度**：否则已经欠到额度的人
一上名单就当场穿仓，"还不上月供"变成"立刻死"，和"挂着名单继续活着挣钱"的设定相反。

| 13 | 60 天满且收益率 ≥ 0 | 🌤 六十天（钱没多，人也没散） |
| 14 | 60 天满 | 🌧 六十天（钱没了，人还在） |

每个结局配一段引文，语气是克制的、不说教的。**这是这个游戏的核心资产，改文案时要保持这个调性**：
不指责玩家，只陈述后果。

## 已知的设计问题

用脚本对 63 张卡做了支配选项检测（某一边在所有维度上都不差于另一边，
且至少一项更好），结果 **18 张卡没有真实选择**，占 29%：

| 卡 | 永远选 | 文本 |
|---|---|---|
| c003 | 右滑 | 你到底亏了多少？我要听实话。 |
| c007 | 左滑 | 爸爸，你为什么总在看手机？ |
| c008 | 右滑 | 今晚家长会，你来不来？ |
| c013 | 左滑 | 他第一次叫爸爸。你正在看盘。 |
| c014 | 右滑 | 下个月房租要涨 800。 |
| c016 | 右滑 | 今年年终奖取消，改成期权，大家理解一下。 |
| c017 | 左滑 | HR 找你聊了十分钟。工位上的东西，你可以明天来收拾。 |
| c018 | 左滑 | 对方已读，没有回。 |
| c019 | 右滑 | 我们组缺人，就是降薪三成。来不来？ |
| c031 | 左滑 | 有人凑到你耳边说了几句，就几句。 |
| c032 | 左滑 | 血压偏高，熬夜太多。医生让你少盯屏幕。 |
| c033 | 左滑 | 你还没睡。屏幕的蓝光里，那根线还在跳。 |
| c034 | 右滑 | 你盯着屏幕，忽然问自己：我到底在干什么？ |
| c051 | 左滑 | 公司公告：筹划重大事项，明日起停牌，复牌时间待定。 |
| c052 | 左滑 | 还是没有复牌的消息。 |
| c056 | 左滑 | 老师说跟着操作一年十倍，先交 8,888 会员费，名额有限。 |
| c061 | 右滑 | 别天天看了，每月固定买一点就行，长期拿着。 |
| c062 | 左滑 | 你今年的收益，跑赢了 1.2% 的人。 |

**检测方法的局限**：只算了显式数值，没算叙事价值。有些卡本来就是「没有好选择」
的处境卡（比如停牌期间），支配是刻意的。

但另外一些是真问题。例如 c032 体检报告：

- 右滑「没事，我扛得住」：心态 −6
- 左滑「今晚不看了」：心态 +10

一边纯亏心态，一边纯赚心态，没有任何权衡。玩家学会「永远左滑」之后，
这张卡就退化成了一个按键。

**建议方向**：给「好选择」加一个隐性代价。比如「今晚不看了」应该让
当天无法处理某件事（错过行情 / 错过一张卡），或者第二天心态回落。
让每个选择都有代价，是这个游戏的核心张力所在。

> 这个清单是待讨论项，不是结论。数值改动应该在 Mac 端的代码里做，
> 在 Windows 上只做分析和提案。
